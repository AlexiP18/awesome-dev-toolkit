# Temp-Mail

> Generador de direcciones de correo electrónico temporales desechables con bandeja de entrada en tiempo real, ideal para registros efímeros y pruebas de flujos de verificación.

**👤 Publicado / Recomendado por:** Precis0x ([@precisox](https://x.com/precisox))

## 💡 ¿Por qué destaca?
- Creación instantánea de inbox temporal sin registro ni contraseña

- Recepción de correos en tiempo real con adjuntos incluidos

- Extensión de navegador y app móvil disponibles

- API y planes de dominio personalizado para pruebas automatizadas

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para probar envíos de emails transaccionales, verificar plantillas de onboarding o registrarte en servicios que no quieres vincular a tu correo principal.
