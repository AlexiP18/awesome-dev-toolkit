# OpenSandbox

> Sandbox open-source y extensible para ejecutar agentes de IA en entornos aislados, con soporte para código, navegación web, escritorios completos y CLIs de agentes como Claude Code o Cursor.

**👤 Publicado / Recomendado por:** Nix0n ([@UnTalNixon_exe](https://x.com/UnTalNixon_exe))

## 💡 ¿Por qué destaca?
- Entornos aislados reales para agentes de IA con ejecución de código, navegación web y control de escritorios completos.

- SDKs en 5 lenguajes e integración con Docker, Kubernetes, gVisor, Kata y Firecracker.

- Incluye Credential Vault y servidor MCP listo para conectar agentes autónomos de forma segura.

- Licencia Apache 2.0 y más de 16k estrellas en GitHub, con soporte para Claude Code, Cursor, Codex y Gemini CLI.

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo cuando necesites ejecutar agentes autónomos o código generado por IA sin comprometer el host; revisa la compatibilidad con Kubernetes/gVisor si buscas aislamiento fuerte en producción.
