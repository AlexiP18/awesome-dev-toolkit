# MoneyPrinterTurbo

> Proyecto open source que automatiza la creación completa de vídeos cortos a partir de un simple tema: la IA redacta el guion, selecciona clips HD, sintetiza la voz, añade subtítulos y música, y entrega el vídeo final listo para publicar.

**👤 Publicado / Recomendado por:** Alba ([@albacnt](https://x.com/albacnt))

## 💡 ¿Por qué destaca?
- Pipeline completo automático: tema → guion → búsqueda de vídeos HD → voz TTS → subtítulos → música → render final

- Soporta formato vertical 9:16 para TikTok/Reels/Shorts y horizontal 16:9 para YouTube, con generación por lotes de múltiples vídeos

- Compatible con múltiples proveedores de LLM: GPT, Gemini, DeepSeek, Ollama y otros modelos configurables

- Código abierto y autohospedable, lo que permite personalizar plantillas, voces y fuentes de stock

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para escalar canales de contenido tipo faceless: clona el repo, configura tu API key del LLM y del servicio TTS, y ejecuta la generación en lote con temas programados; revisa siempre los clips de stock y la locución antes de publicar para mantener calidad de marca.
