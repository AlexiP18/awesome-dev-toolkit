# Herk Edit Kit

> Un kit de edición que capacita a Codex o Claude Code con habilidades de edición para cortar tiempos muertos, encontrar errores, añadir subtítulos, organizar B-roll y construir gráficos en movimiento en videos, reels y YouTube Shorts.

**👤 Publicado / Recomendado por:** Rimsha Bhardwaj ([@heyrimsha](https://x.com/heyrimsha))

## 💡 ¿Por qué destaca?
- Habilita a Codex o Claude Code para realizar tareas de edición de video.

- Automatiza el corte de silencios y la detección de errores en el metraje.

- Facilita la adición de subtítulos y la organización de material B-roll.

- Permite la creación de gráficos en movimiento y utiliza plantillas HyperFrames.

## 📝 Notas Personales (Segundo Cerebro)
- Útil para desarrolladores y creadores que desean integrar capacidades de IA conversacional (como Codex o Claude) directamente en su flujo de trabajo de edición de video.
