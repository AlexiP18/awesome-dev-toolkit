# RAG_Techniques

> Repositorio de notebooks ejecutables que implementa técnicas avanzadas de RAG para mejorar recuperación y generación con LLMs.

**👤 Publicado / Recomendado por:** Precis0x ([@precisox](https://x.com/precisox))

## 💡 ¿Por qué destaca?
- Cada técnica RAG se explica en un notebook independiente

- Cubre embeddings, búsqueda semántica, vector databases y agentic RAG

- Ejemplos prácticos con LangChain, LlamaIndex y OpenAI

- Útil para comparar enfoques de recuperación antes de producción
