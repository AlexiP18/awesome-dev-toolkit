# changedetection.io

> Monitor self-hosted en Python que vigila cualquier página web y envía una notificación por email, webhook o Telegram en el instante en que su contenido cambia.

**👤 Publicado / Recomendado por:** Sentient ([@sentient_agency](https://x.com/sentient_agency))

## 💡 ¿Por qué destaca?
- Selección de elementos CSS o XPath para vigilar solo la parte relevante de la página

- Notificaciones vía webhook, email, Telegram y Slack

- Historial de cambios con diff visual entre versiones

- Soporte de navegador headless y proxies para páginas con JavaScript

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para rastrear bajadas de precio, ofertas de empleo o cambios en webs de competidores; activa el navegador headless si la página renderiza con JS.
