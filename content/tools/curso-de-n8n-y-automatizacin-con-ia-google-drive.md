# Curso de n8n y Automatización con IA (Google Drive)

> Curso en vídeo y material de apoyo sobre n8n, la plataforma de automatización de flujos de trabajo que permite orquestar APIs, modelos de IA y agentes mediante nodos visuales y código JavaScript personalizado.

**👤 Publicado / Recomendado por:** ayo.artss ([@madamayo_](https://x.com/madamayo_))

## 💡 ¿Por qué destaca?
- Construcción de workflows automatizados con nodos de n8n y webhooks

- Integración de modelos de lenguaje y agentes de IA dentro de los flujos

- Uso de self-hosting y despliegue de n8n con Docker

- Ejemplos de automatización de tareas repetitivas y pipelines de datos

## 📝 Notas Personales (Segundo Cerebro)
- Instala n8n en local con Docker mientras sigues el curso y reproduce cada workflow para entender el paso de datos entre nodos y el manejo de errores.
