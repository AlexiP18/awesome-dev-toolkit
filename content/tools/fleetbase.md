# Fleetbase

> Sistema operativo logístico modular (LSOS) de código abierto escrito en JavaScript que centraliza pedidos, entregas, gestión de flotas, inventario y seguimiento de envíos mediante APIs extensibles y módulos conectables.

**👤 Publicado / Recomendado por:** Snow Brave ([@Sn0wbrave](https://x.com/Sn0wbrave))

## 💡 ¿Por qué destaca?
- Arquitectura modular tipo 'extensions' que permite añadir módulos de gestión de pedidos, almacenes, inventario y transporte sobre un mismo núcleo

- API HTTP y servicios backend en Node.js/JavaScript para integrar tracking en tiempo real, optimización de rutas y última milla

- Incluye aplicaciones para conductores (driver-app), consola de administración y paneles de monitoreo de flotas listos para desplegar

- Soporta despliegue autoalojado (self-hosted) con soporte para Docker, lo que facilita su integración en infraestructuras propias

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo si necesitas construir o autoalojar una plataforma logística completa (TMS/DMS) sin partir de cero: revisa la documentación de extensiones y el API para conectar tus propios sistemas de e-commerce o ERP antes de desplegar en producción.
