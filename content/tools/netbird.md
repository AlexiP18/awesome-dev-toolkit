# NetBird

> Plataforma open source de red privada basada en WireGuard que combina overlay network y Zero Trust Network Access para conectar servicios y dispositivos de forma segura.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Red overlay sobre WireGuard con gestión de identidades y políticas de acceso

- Zero Trust Network Access (ZTNA) autohospedable o gestionado

- Configuración de conectividad segura entre servidores, contenedores y equipos remotos

## 📝 Notas Personales (Segundo Cerebro)
- Empléala para montar una VPN mesh entre entornos de desarrollo, servidores cloud y equipos del equipo sin exponer servicios directamente a Internet.
