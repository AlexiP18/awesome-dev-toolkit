# SearXNG

> Metabuscador self-hosted en Python que agrega resultados de Google, Bing y más de 100 motores simultáneamente sin perfiles, sin logs y sin publicidad.

**👤 Publicado / Recomendado por:** Sentient ([@sentient_agency](https://x.com/sentient_agency))

## 💡 ¿Por qué destaca?
- Federación y agregación de resultados de más de 100 motores de búsqueda

- Sin registro de IPs, historial ni cookies de seguimiento

- Despliegue con Docker Compose y configuración por variables de entorno

- API JSON para consumir resultados desde scripts o agentes de IA

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo como motor de búsqueda interno para tu equipo o como backend de búsqueda vía API JSON en agentes y automatizaciones.
