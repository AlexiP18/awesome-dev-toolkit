# Learn Claude Code

> Proyecto educativo que recrea desde cero un agente tipo Claude Code para aprender cómo funcionan internamente los agentes de codificación.

**👤 Publicado / Recomendado por:** Leonard Rodman ([@RodmanAi](https://x.com/RodmanAi))

## 💡 ¿Por qué destaca?
- Implementa un agent harness mínimo inspirado en Claude Code usando Bash y Python

- Enfoque didáctico con ejemplos para entender herramientas, prompts y bucles del agente

- Repositorio open source con temas de agent-development, tutorial y enseñanza

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para estudiar la arquitectura de un coding agent antes de construir el tuyo propio o adaptar este harness a flujos internos.
