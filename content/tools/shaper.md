# shaper

> Herramienta open source escrita en Go para visualizar y compartir datos usando SQL, impulsada por DuckDB.

**👤 Publicado / Recomendado por:** 𝐍𝐨𝐚𝐡 ([@noahelhadedy](https://x.com/noahelhadedy))

## 💡 ¿Por qué destaca?
- Consultas y visualización de datos totalmente en SQL

- Motor DuckDB para análisis rápido

- Dashboards compartibles para explorar datasets

- Repositorio con más de 1.200 estrellas en GitHub

## 📝 Notas Personales (Segundo Cerebro)
- Úsala para montar dashboards ligeros y explorar datos analíticos sin salir del flujo SQL.
