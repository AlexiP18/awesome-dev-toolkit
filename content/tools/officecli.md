# OfficeCLI

> Suite de Office por línea de comandos diseñada para agentes de IA que permite leer, editar y automatizar Word, Excel y PowerPoint sin instalar Microsoft Office.

**👤 Publicado / Recomendado por:** PA13L0 ([@Fluyeporlaweb](https://x.com/Fluyeporlaweb))

## 💡 ¿Por qué destaca?
- Un solo binario sin dependencias ni instalación de Office

- Soporta archivos docx, xlsx y pptx desde la CLI

- Pensado para agentes como Claude Code y Codex

- Código abierto y escriturado en C#

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para automatizar la generación y edición de documentos ofimáticos dentro de pipelines de agentes de IA sin depender de suites comerciales.
