# Cognee

> Plataforma open source de memoria para agentes de IA que combina grafos de conocimiento y datos conectados para ofrecer memoria persistente a largo plazo.

**👤 Publicado / Recomendado por:** Shruti Codes ([@Shruti_0810](https://x.com/Shruti_0810))

## 💡 ¿Por qué destaca?
- Capa de memoria persistente de largo plazo para agentes

- Integración de knowledge graphs con bases de datos vectoriales

- Compatible con modelos pequeños y flujos de context engineering

## 📝 Notas Personales (Segundo Cerebro)
- Úsala para dotar a asistentes conversacionales de memoria duradera sin reentrenar el modelo.
