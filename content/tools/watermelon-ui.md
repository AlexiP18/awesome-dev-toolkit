# Watermelon UI

> Una colección gratuita y de código abierto de más de 600 componentes, animaciones, bloques y paneles de control para React, diseñados para integrarse con Tailwind CSS y shadcn/ui.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Más de 600 componentes, bloques y dashboards para React.

- Compatible con Tailwind CSS y shadcn/ui.

- Componentes gratuitos y de código abierto.

- Permite copiar el código o instalar vía shadcn CLI.

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para acelerar el desarrollo de interfaces de usuario en proyectos React, ofreciendo una amplia variedad de elementos pre-construidos y personalizables.
