# WeDoFlow

> Biblioteca con más de 1.300 páginas de sitios web reales organizadas por secciones, ideal para estudiar patrones de maquetación, jerarquía visual y copy en interfaces SaaS.

**👤 Publicado / Recomendado por:** Vullnet Ademaj ([@VullnetAdemaj](https://x.com/VullnetAdemaj))

## 💡 ¿Por qué destaca?
- Más de 1.300 páginas web catalogadas por tipo de sección

- Referencias directas de hero, pricing, features y footer

- Permite filtrar patrones de diseño ya validados en producto

## 📝 Notas Personales (Segundo Cerebro)
- Empléalo durante la fase de research de UI para justificar decisiones de layout y evitar rediseñar secciones comunes desde cero.
