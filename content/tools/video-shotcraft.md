# video-shotcraft

> Habilidad de IA para Claude Code y Codex que genera vídeos de producto con acabado cinematográfico utilizando código, incluyendo flujos de trabajo con Remotion y una amplia colección de plantillas reutilizables.

**👤 Publicado / Recomendado por:** Rodev ([@romandevz](https://x.com/romandevz))

## 💡 ¿Por qué destaca?
- Genera vídeos de producto con un acabado cinematográfico usando código.

- Incluye flujos de trabajo con Remotion y plantillas reutilizables.

- Ofrece 124 'shot recipe cards' y 150 vistas previas de movimiento.

- Soporta sincronización de ritmo, diseño de sonido y exportación a JianYing (CapCut CN).

## 📝 Notas Personales (Segundo Cerebro)
- Perfecto para desarrolladores que desean crear promos de productos de alta calidad de forma automatizada y programática para marketing o demostraciones.
