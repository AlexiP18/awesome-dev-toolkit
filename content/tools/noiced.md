# Noiced

> Colección curada de sitios web excepcionalmente bien diseñados, publicada a diario como fuente de inspiración para interfaces modernas.

**👤 Publicado / Recomendado por:** Tran Mau Tri Tam ✪ ([@tranmautritam](https://x.com/tranmautritam))

## 💡 ¿Por qué destaca?
- Catálogo de webs seleccionadas por calidad de diseño

- Actualización diaria de referencias visuales

- Ideal para estudiar layouts, tipografía y paletas en proyectos reales

## 📝 Notas Personales (Segundo Cerebro)
- Empléalo al inicio de un proyecto frontend para definir dirección visual y comparar patrones de navegación, grids y sistemas de color.
