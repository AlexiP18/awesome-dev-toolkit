# dioramas

> Framework open source para crear páginas web 3D interactivas con una estética cinematográfica, combinando recursos generados con IA, Three.js y WebGL para construir experiencias inmersivas en el navegador.

**👤 Publicado / Recomendado por:** Rodev ([@romandevz](https://x.com/romandevz))

## 💡 ¿Por qué destaca?
- Permite crear sitios web 3D interactivos con un estilo cinematográfico.

- Integra recursos generados con IA (Nano Banana 2 + Meshy 7.1).

- Utiliza Three.js y WebGL para renderizar experiencias inmersivas.

- Incluye 20 sitios de ejemplo para empezar a construir.

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para desarrolladores y diseñadores web que quieran crear landings o portfolios únicos con elementos 3D y generativos para una mayor interacción.
