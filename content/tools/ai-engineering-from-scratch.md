# AI Engineering from Scratch

> Curso gratuito y open source de AI Engineering desde primeros principios, con 542 lecciones que van desde las matemáticas base y los modelos hasta agentes, evaluación y despliegue en producción.

> 🎓 **Promoción Académica:** Disponible para estudiantes o instituciones educativas.

**👤 Publicado / Recomendado por:** santi ([@santtiagom_](https://x.com/santtiagom_))

## 💡 ¿Por qué destaca?
- 542 lecciones gratuitas y open source organizadas como currículo progresivo desde cero

- Cubre fundamentos matemáticos, modelos, tokenizers, evaluación y puesta en producción de sistemas de IA

- Incluye módulos prácticos de RAG, MCP (Model Context Protocol), tools y Agent Engineering

- Aborda sistemas multi-agente y patrones de orquestación de agentes LLM

## 📝 Notas Personales (Segundo Cerebro)
- Ideal como ruta de aprendizaje estructurada para desarrolladores que quieren pasar de usar APIs de LLM a construir sistemas RAG, servidores MCP y agentes orquestados; sigue el orden del currículo y complementa cada módulo con un proyecto propio para consolidar.
