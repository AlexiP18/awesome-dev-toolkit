# Open Code Review

> Revisor de código con IA liberado como open source por Alibaba, compatible con Claude Code, Codex y Cursor; el enlace al repo no venía en el tuit (estaba en los comentarios), por eso se guarda el permalink.

**👤 Publicado / Recomendado por:** José Siles | AI | Data ([@josesilesdata](https://x.com/josesilesdata))

## 💡 ¿Por qué destaca?
- Lee los cambios de Git y comenta línea por línea, también repos enteros

- Detecta NPE, concurrencia, XSS e inyección SQL

- Según su benchmark usa ~1/9 de los tokens de Claude Code con el mismo modelo

- Se instala con npm y usa modelos de OpenAI o Anthropic
