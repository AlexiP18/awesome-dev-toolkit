# system_prompts_leaks

> Recopilación de los system prompts filtrados de modelos como Claude, GPT-5.6, Gemini, Grok, Cursor y Copilot, útil para estudiar cómo se comportan y diseñar mejores prompts.

**👤 Publicado / Recomendado por:** PA13L0 ([@Fluyeporlaweb](https://x.com/Fluyeporlaweb))

## 💡 ¿Por qué destaca?
- Incluye prompts de Claude Code, GPT, Gemini, Grok, Cursor y Copilot

- Repositorio citado en el Washington Post

- Se actualiza de forma regular con nuevas filtraciones

## 📝 Notas Personales (Segundo Cerebro)
