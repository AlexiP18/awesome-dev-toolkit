# DeerFlow

> DeerFlow es un harness de SuperAgentes open source de ByteDance, escrito en Python, que orquesta subagentes, sandboxes, memorias y herramientas para resolver tareas de larga duración como investigar, escribir código o generar presentaciones y videos.

**👤 Publicado / Recomendado por:** Fran Pradas | Ingeniero de IA ([@franpradasAI](https://x.com/franpradasAI))

## 💡 ¿Por qué destaca?
- Arquitectura multiagente construida sobre LangChain y LangGraph con subagentes especializados y gateway de mensajes

- Incluye sandboxes de ejecución, sistema de memorias persistentes y un catálogo de herramientas y skills conectables

- Capacidades de deep research con navegación web, generación de código, presentaciones de diapositivas, podcasts y videos

- Stack mixto Python/TypeScript con soporte para modelos LLM configurables y ejecución local de tareas en tu propia máquina

## 📝 Notas Personales (Segundo Cerebro)
- Clónalo desde el repo, configura tus claves de API de LLM y usa los subagentes para automatizar flujos de investigación y prototipado; conviene revisar los requisitos de Docker y Node.js antes de desplegarlo en local.
