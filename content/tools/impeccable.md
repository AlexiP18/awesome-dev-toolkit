# Impeccable

> Skill para agentes de código que aporta el vocabulario de diseño necesario para auditar, criticar y mejorar interfaces web, detectando y corrigiendo el temido 'AI slop' visual antes de que llegue a producción.

**👤 Publicado / Recomendado por:** Miguel Ángel Durán ([@midudev](https://x.com/midudev))

## 💡 ¿Por qué destaca?
- Revisa layout, usabilidad, contraste y accesibilidad de la interfaz generada por el agente

- Proporciona comandos de control como 'polish' y 'bolder' para dirigir el estilo visual, y 'critique' y 'audit' para evaluar el resultado

- Se integra como agent-skill en el flujo de trabajo de asistentes de código, escrito en Rust

- Orientada explícitamente a frenar el 'AI slop': diseños genéricos, inconsistentes y con mala jerarquía visual

## 📝 Notas Personales (Segundo Cerebro)
- Úsala cuando un agente de IA genere componentes o páginas y quieras una pasada automática de crítica de diseño, contraste y accesibilidad; ideal antes de abrir un PR de frontend para evitar interfaces planas o con problemas de WCAG.
