# dsh-blender-plugin

> Un plugin para Blender que integra directamente herramientas de IA, permitiendo a los usuarios generar modelos 3D y acelerar el proceso creativo con un control GUI y opciones para pausar el agente de IA.

**👤 Publicado / Recomendado por:** Rodev ([@romandevz](https://x.com/romandevz))

## 💡 ¿Por qué destaca?
- Integra 15 herramientas de modelo impulsadas por IA directamente en Blender.

- Soporta control AI-driven GUI y dsh-TUI para la interfaz.

- Permite la generación de modelos 3D y acelera el proceso creativo.

- Compatible con WSL, Windows y macOS.

## 📝 Notas Personales (Segundo Cerebro)
- Esencial para artistas 3D y desarrolladores que desean potenciar sus flujos de trabajo en Blender con capacidades de inteligencia artificial.
