# Otsu

> Prototipo web experimental de interfaz que introduce las novedades 'melt' y 'unlit cells', publicado como demo en vivo mediante un snapshot para mostrar trabajo de diseño en progreso.

**👤 Publicado / Recomendado por:** Jarek ([@jarekceborski](https://x.com/jarekceborski))

## 💡 ¿Por qué destaca?
- Demo pública accesible vía LocalCan Snapshot sin necesidad de build ni despliegue propio

- Explora patrones visuales de celdas ('melt' y 'unlit cells') como experimento de interacción y render en el navegador

- Sirve como referencia de cómo iterar y compartir prototipos de UI en etapas tempranas

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo como inspiración para experimentos de UI y como caso práctico de flujo WIP: prototipo local + snapshot público para recibir feedback rápido de diseño.
