# DesignPass

> Componentes React animados de nivel premium con física de resortes, efectos 3D y fondos WebGL, instalables vía shadcn CLI o copiando el código; gratis y con licencia MIT.

**👤 Publicado / Recomendado por:** KASUN ([@kasuncfdo](https://x.com/kasuncfdo))

## 💡 ¿Por qué destaca?
- Animaciones con spring physics para transiciones naturales

- Efectos 3D y fondos WebGL listos para integrar

- Instalación mediante shadcn CLI o copy-paste del código fuente

- Licencia MIT, gratuito para uso comercial

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para añadir fondos WebGL y animaciones físicas realistas a landings o portfolios React; instala con el CLI de shadcn y ajusta los parámetros de spring para el timing deseado.
