# Componly

> Colección curada de componentes de sistemas de diseño reales, que permite explorar implementaciones y reutilizar patrones de interfaz en proyectos frontend.

**👤 Publicado / Recomendado por:** Abraham John ([@Abmankendrick](https://x.com/Abmankendrick))

## 💡 ¿Por qué destaca?
- Agrupa componentes de múltiples design systems de referencia

- Facilita la comparación de implementaciones y estilos

- Ideal para inspiración y adopción de patrones de UI

## 📝 Notas Personales (Segundo Cerebro)
- Explora componentes similares al que necesitas construir para ver cómo otras empresas resuelven problemas de interfaz.
