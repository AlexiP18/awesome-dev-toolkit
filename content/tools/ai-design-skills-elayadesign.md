# AI Design Skills (elayadesign)

> Colección de skills de diseño pensadas para agentes de codificación con IA como Cursor Composer, que guían al modelo a generar secciones hero, layouts y UI web con criterio visual profesional en lugar de maquetación genérica.

**👤 Publicado / Recomendado por:** Elaya ([@elayadesigns](https://x.com/elayadesigns))

## 💡 ¿Por qué destaca?
- Skills empaquetadas como instrucciones reutilizables que se cargan en agentes de código (Cursor Composer) para condicionar sus decisiones de diseño

- Enfocadas en la construcción de secciones hero, jerarquía tipográfica, espaciado, paletas y composición visual de landing pages

- Se combinan con el flujo del editor/agente de IA para producir HTML/CSS o componentes de interfaz listos para producción

- Repositorio abierto en GitHub que puede clonarse y adaptarse a un stack frontend propio (React, Tailwind, HTML/CSS)

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo cuando trabajes con Cursor u otro agente de código y quieras elevar la calidad visual de una landing o hero section; clona el repo, revisa el formato de las skills y añádelas como contexto o reglas del proyecto para que el agente aplique el criterio de diseño de forma consistente.
