# Space Type Generator

> Generador interactivo de tipografía cinética que produce composiciones de letras animadas con estética espacial, pensado para diseñadores y desarrolladores que necesitan piezas visuales llamativas sin escribir shaders desde cero.

**👤 Publicado / Recomendado por:** Toolfolio ([@toolfolio](https://x.com/toolfolio))

## 💡 ¿Por qué destaca?
- Interfaz web interactiva con controles en tiempo real para deformar, rotar y animar los glifos tipográficos

- Resultados visuales tipo motion graphics aptos para capturas, vídeo o exportación como referencia de animación

- Enfoque generativo y experimental: cada combinación de parámetros produce una composición tipográfica distinta

- Útil como fuente de inspiración y como base para replicar efectos con CSS, Canvas o WebGL

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para prototipar portadas, hero sections o transiciones tipográficas: genera la animación en la herramienta, captura los fotogramas clave y reprodúcelos en el frontend con CSS transforms o animaciones controladas por JavaScript.
