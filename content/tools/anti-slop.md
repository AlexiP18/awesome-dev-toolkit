# anti-slop

> Conjunto de 38 reglas para agentes de codificación con IA que bloquea diseños de interfaz, textos y comentarios genéricos, ayudando a mantener una UI web con criterio y personalidad.

**👤 Publicado / Recomendado por:** Manish Kumar ([@Manixh02](https://x.com/Manixh02))

## 💡 ¿Por qué destaca?
- 38 reglas que filtran layouts, copy y comentarios genéricos generados por IA

- Compatible con Claude Code, Cursor, Codex y otros agentes de codificación

- Se instala con un solo comando: npx antislop-ai

- Permite aportar criterio de diseño mediante un archivo DESIGN.md

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo en proyectos frontend donde los agentes de IA tienden a producir interfaces repetitivas; instálalo en el repositorio y define un DESIGN.md con las directrices visuales del proyecto para obtener mejores resultados.
