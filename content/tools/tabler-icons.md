# Tabler Icons

> Colección open-source de más de 5.000 iconos SVG vectoriales personalizables, pensada para integrarse en interfaces web y aplicaciones modernas.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Más de 5.000 iconos SVG gratuitos y open-source

- Grosor de trazo y tamaño personalizables

- Paquetes oficiales para React, Vue y otros frameworks

- Uso directo como SVG o mediante componentes

## 📝 Notas Personales (Segundo Cerebro)
- Útil para sustituir iconos genéricos en dashboards, landings y design systems manteniendo consistencia visual y ligereza.
