# Suwayomi-Server

> Servidor self-hosted, sucesor comunitario de Tachiyomi, escrito en Kotlin que aloja miles de fuentes de manga y las sirve a cualquier cliente mediante API web.

**👤 Publicado / Recomendado por:** Sentient ([@sentient_agency](https://x.com/sentient_agency))

## 💡 ¿Por qué destaca?
- Ejecuta extensiones de Tachiyomi en el servidor en lugar del dispositivo

- API GraphQL y cliente web integrado

- Biblioteca, categorías y progreso de lectura centralizados para varios dispositivos

- Despliegue mediante Docker o JAR autónomo

## 📝 Notas Personales (Segundo Cerebro)
- Útil si quieres mantener la biblioteca y el progreso sincronizados entre dispositivos sin depender de una única app móvil.
