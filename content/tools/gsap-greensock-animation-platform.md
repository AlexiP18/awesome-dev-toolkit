# GSAP (GreenSock Animation Platform)

> Motor de animación JavaScript de alto rendimiento para timelines complejas, animaciones de SVG, texto y propiedades CSS con control preciso de easing y secuencias.

**👤 Publicado / Recomendado por:** 露西的百宝箱 ([@Lucy_love_AI](https://x.com/Lucy_love_AI))

## 💡 ¿Por qué destaca?
- Timeline API para encadenar, solapar y escalar animaciones con precisión

- Soporte profundo de SVG: morphing con MorphSVG, trazos con DrawSVG y `stroke-dasharray`

- Plugins de scroll (ScrollTrigger), texto dividido y drag con inercia

- Compatible con cualquier framework y con elementos DOM/canvas

## 📝 Notas Personales (Segundo Cerebro)
- Elige GSAP cuando necesites secuencias coreografiadas, animaciones ligadas al scroll o efectos SVG avanzados que Motion o Anime.js no cubren con la misma precisión.
