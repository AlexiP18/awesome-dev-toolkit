# Tween UI

> Componentes React animados con GSAP y Tailwind CSS bajo la filosofía 'copia el código fuente y haz tuya la animación', escritos en TypeScript e integrables con shadcn/ui.

**👤 Publicado / Recomendado por:** KASUN ([@kasuncfdo](https://x.com/kasuncfdo))

## 💡 ¿Por qué destaca?
- Animaciones construidas con GSAP y GSAP ScrollTrigger

- Estilos con Tailwind CSS y compatibilidad con shadcn-ui

- Código fuente en TypeScript listo para copiar y modificar (sin dependencia de paquete opaco)

- Tópicos del repo: components, motion, nextjs, ui-components

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo cuando quieras animaciones de scroll y transiciones complejas en React/Next.js con control total del código; clona o copia el componente y adapta los timelines de GSAP a tu diseño.
