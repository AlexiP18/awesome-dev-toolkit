# OpenRouter

> Gateway unificado que expone cientos de modelos de distintos proveedores bajo una sola API key compatible con el formato OpenAI, facilitando pruebas comparativas de prompts. Su capa gratuita permite 50 peticiones diarias a modelos free.

**👤 Publicado / Recomendado por:** m0h ([@exploraX_](https://x.com/exploraX_))

## 💡 ¿Por qué destaca?
- Una única API key para acceder al catálogo de modelos de múltiples proveedores

- 50 requests/día en modelos gratuitos; sube a 1.000/día con una compra única de $10

- Compatible con SDKs estilo OpenAI, lo que simplifica cambiar de modelo sin tocar código

- Permite comparar latencia, calidad y precio del mismo prompt entre modelos

## 📝 Notas Personales (Segundo Cerebro)
- Los $10 de recarga única son la mejor inversión de toda la lista: multiplican por 20 el límite diario de forma permanente. Úsalo como capa de abstracción para evaluar modelos antes de fijar uno en producción.
