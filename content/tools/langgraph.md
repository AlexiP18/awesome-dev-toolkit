# LangGraph

> Biblioteca para construir agentes con estado como grafos, ideal para flujos agénticos resilientes y orquestación de pasos.

**👤 Publicado / Recomendado por:** Matt Dancho (Business Science) ([@mdancho84](https://x.com/mdancho84))

## 💡 ¿Por qué destaca?
- Modela agentes y workflows como grafos con estado.

- Soporta ciclos, ramificaciones y persistencia de estado.

- Pensado para agentes de producción y orquestación multi-paso.

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo cuando necesites control explícito sobre el flujo de un agente, reanudación de estado o workflows con múltiples herramientas.
