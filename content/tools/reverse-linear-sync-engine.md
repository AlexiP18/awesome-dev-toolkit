# Reverse Linear Sync Engine

> Ingeniería inversa documentada del motor de sincronización de Linear, que explica cómo la app mantiene la mayoría de los datos en el navegador y los alinea con el backend para lograr una UX casi instantánea.

**👤 Publicado / Recomendado por:** Alvaro ([@alvarombt](https://x.com/alvarombt))

## 💡 ¿Por qué destaca?
- Análisis interno del sync engine de Linear: almacenamiento local en el navegador y reconciliación asíncrona con el servidor

- Documentación de los mecanismos de sincronización de datos y resolución de conflictos que evitan esperas por respuesta del backend

- Repositorio en JavaScript con tópicos de data-sync, collaboration y reverse-engineering, respaldado por el propio CTO de Linear como referencia completa

- Patrones aplicables a arquitecturas local-first y optimistic UI en aplicaciones web de alta interactividad

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo como referencia de arquitectura si estás diseñando una web app con estado local persistente, optimistic updates o sincronización offline-first, y quieres entender cómo evitar latencias percibidas por el usuario.
