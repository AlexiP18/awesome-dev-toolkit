# tsParticles

> Una librería TypeScript para crear fácilmente efectos de partículas altamente personalizables, como explosiones de confeti y fuegos artificiales, que se pueden usar como fondos animados para sitios web y aplicaciones.

**👤 Publicado / Recomendado por:** eigen ([@e1genqq](https://x.com/e1genqq))

## 💡 ¿Por qué destaca?
- Efectos de partículas altamente personalizables para cualquier web

- Componentes listos para integrar con React, Vue, Angular y más

- Animaciones de confeti, fuegos artificiales y fondos dinámicos

- Basado en TypeScript para mayor robustez y escalabilidad

## 📝 Notas Personales (Segundo Cerebro)
- Útil para añadir dinamismo visual y atractivos fondos animados a cualquier sitio web o aplicación interactiva, mejorando la primera impresión y el engagement del usuario.
