# Ray.so

> Generador de capturas de código con resaltado de sintaxis, temas y fondos listos para compartir en redes o documentación.

**👤 Publicado / Recomendado por:** Alejo ([@ecommartinez](https://x.com/ecommartinez))

## 💡 ¿Por qué destaca?
- Temas de sintaxis populares y fondo degradado

- Control de padding, fuente y número de líneas

- Exportación PNG y SVG a 2x

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para ilustrar snippets en un README, issue o post técnico manteniendo el formato legible.
