# Supabase

> Una plataforma de desarrollo de código abierto basada en PostgreSQL que ofrece una alternativa a Firebase, proporcionando una base de datos dedicada y herramientas para construir aplicaciones web, móviles y de IA con autenticación y APIs en tiempo real.

**👤 Publicado / Recomendado por:** Harshil Tomar ([@Hartdrawss](https://x.com/Hartdrawss))

## 💡 ¿Por qué destaca?
- Plataforma de desarrollo full-stack con una base de datos PostgreSQL dedicada.

- Ofrece autenticación de usuarios, bases de datos en tiempo real y APIs RESTful/GraphQL.

- Soporte para características de IA como pgvector para embeddings.

- Una alternativa de código abierto y autoalojable a Firebase.

## 📝 Notas Personales (Segundo Cerebro)
- Considera Supabase para proyectos que requieren un backend completo con base de datos, autenticación y funcionalidades en tiempo real, manteniendo el control total de los datos.
