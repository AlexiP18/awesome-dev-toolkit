# MengTo Skills

> Repositorio de agent skills para diseño y desarrollo web que potencian asistentes como Claude, Codex o Cursor y otros agentes de codificación con IA.

**👤 Publicado / Recomendado por:** Tran Mau Tri Tam ✪ ([@tranmautritam](https://x.com/tranmautritam))

## 💡 ¿Por qué destaca?
- Skills reutilizables para agentes de código (Claude, Codex, Cursor)

- Enfoque en dirección de arte, layout y calidad de UI web

- Proyecto open source con más de 7.200 estrellas en GitHub

## 📝 Notas Personales (Segundo Cerebro)
- Clónalo y monta las skills en tu carpeta de agente para que genere interfaces con criterio visual consistente; revisa cada skill antes de usarla en producción.
