# Web-to-App

> Toolkit Android escrito en Kotlin que empaqueta cualquier sitio web en una APK firmada mediante un WebView configurable, con soporte para runtimes Node.js, PHP y Python.

**👤 Publicado / Recomendado por:** divyansh tiwari ([@DivyanshT91162](https://x.com/DivyanshT91162))

## 💡 ¿Por qué destaca?
- WebView configurable con firma de APK hecha en el propio dispositivo

- Soporte de runtimes Node.js, PHP y Python sin build remoto

- Proyecto Kotlin con más de 7.000 estrellas en GitHub

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para publicar rápido una versión móvil de tu web app o prototipos internos; revisa las políticas de Google Play sobre apps basadas en WebView.
