# Excalidraw

> Pizarra infinita open-source con estilo dibujado a mano que puede incrustarse como componente React y sustituye a Miro o FigJam para wireframes y diagramas colaborativos.

**👤 Publicado / Recomendado por:** divyansh tiwari ([@DivyanshT91162](https://x.com/DivyanshT91162))

## 💡 ¿Por qué destaca?
- Componente React embebible con API para controlar el canvas

- Colaboración en tiempo real con cifrado de extremo a extremo

- Más de 120.000 estrellas en GitHub y exportación a PNG/SVG (MIT)
