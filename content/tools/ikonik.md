# Ikonik

> Librería de iconos curada que ofrece sets vectoriales consistentes para interfaces, facilitando la integración de iconografía uniforme en design systems y componentes frontend.

**👤 Publicado / Recomendado por:** Vullnet Ademaj ([@VullnetAdemaj](https://x.com/VullnetAdemaj))

## 💡 ¿Por qué destaca?
- Sets de iconos vectoriales listos para importar en Figma o código

- Estilos consistentes para mezclar iconos sin romper la UI

- Enfoque en iconografía de producto y aplicaciones

## 📝 Notas Personales (Segundo Cerebro)
- Úsala cuando necesites un paquete de iconos coherente para un design system; verifica compatibilidad de tamaño y grosor de trazo con tu escala tipográfica.
