# React Postprocessing

> Envoltorio declarativo del pipeline de postprocesado de Three.js para React Three Fiber, con efectos como bloom, profundidad de campo, viñeta y antialiasing.

**👤 Publicado / Recomendado por:** 露西的百宝箱 ([@Lucy_love_AI](https://x.com/Lucy_love_AI))

## 💡 ¿Por qué destaca?
- Efectos declarativos como `Bloom`, `DepthOfField`, `Vignette` y `Noise`

- Gestión automática del `EffectComposer` y del orden de pases

- Compatible con SMAA/FXAA y selección de efectos por rendimiento

## 📝 Notas Personales (Segundo Cerebro)
- Añádelo al final del proyecto 3D para dar acabado cinematográfico (bloom sutil, DOF) cuidando el coste en GPU en móviles.
