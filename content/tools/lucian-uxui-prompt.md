# Lucian UX/UI Prompt

> Colección open source de 400 templates de UX/UI con prompts y código listos para copiar, incluyendo 200 nuevos elementos de animación e interacción para webs reales.

**👤 Publicado / Recomendado por:** 루샨 lucian ([@lucian__03](https://x.com/lucian__03))

## 💡 ¿Por qué destaca?
- 400 templates UX/UI gratuitos y totalmente open source (200 añadidos en esta actualización)

- Incluye interacciones avanzadas: flowcharts automatizados, gráficos de datos en 3D, burbujas que se reagrupan por criterio, texto con efecto de onda y redes de relaciones interactivas

- Soporte completo de tema claro y oscuro, además de interfaz en coreano e inglés

- Cada template permite copiar el prompt y el código directamente desde el sitio

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo como fuente de inspiración y punto de partida para maquetar dashboards, visualizaciones de datos y microinteracciones en React/Vue/CSS, copiando el prompt para generar el componente con tu agente de IA o pegando el código directamente.
