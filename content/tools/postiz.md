# Postiz

> Una plataforma de código abierto para la programación de publicaciones en redes sociales, diseñada como una herramienta agentic definitiva para automatizar y gestionar la estrategia de contenido en múltiples canales.

**👤 Publicado / Recomendado por:** Harshil Tomar ([@Hartdrawss](https://x.com/Hartdrawss))

## 💡 ¿Por qué destaca?
- Plataforma de código abierto para la programación avanzada de publicaciones en redes sociales.

- Incorpora funcionalidades 'agentic' para una automatización inteligente del contenido.

- Construida con Next.js y TypeScript, ofreciendo flexibilidad y escalabilidad.

- Permite la autogestión y el despliegue en la nube para un control total.

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para creadores de contenido y empresas que buscan una solución potente y personalizable para gestionar y automatizar sus publicaciones en redes sociales.
