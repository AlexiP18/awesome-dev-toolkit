# Jitter

> Herramienta de motion design en la web para crear animaciones profesionales de interfaces en minutos, con exportación a video o formatos usables en producto.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Editor de animaciones colaborativo basado en navegador

- Exportación de animaciones a video/GIF y recursos para prototipos de UI

- Curvas de animación, easing y timeline orientados a microinteracciones de producto

## 📝 Notas Personales (Segundo Cerebro)
- Úsala para crear microinteracciones y demos animadas de componentes de UI que luego replicarás con CSS o librerías de animación en el frontend.
