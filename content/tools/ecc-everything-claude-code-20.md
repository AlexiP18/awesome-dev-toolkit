# ECC (Everything Claude Code) 2.0

> Repositorio que empaqueta 262 skills públicas, instincts, memoria compartida, seguridad y flujos de trabajo listos para instalar, con el fin de que agentes de código como Claude Code, Codex, Cursor u OpenCode rindan como los usan los mejores equipos.

**👤 Publicado / Recomendado por:** Marco ([@maarcoofdezz](https://x.com/maarcoofdezz))

## 💡 ¿Por qué destaca?
- 262 skills para coding, investigación, seguridad, media, enterprise y flujos de agentes, reutilizables sin reescribir prompts entre entornos

- AgentShield: escanea la configuración de Claude Code en busca de vulnerabilidades, inyecciones de prompt y secretos expuestos

- Modo red team/blue team con 3 agentes Opus en paralelo (atacante, defensor y auditor) más 1.282 tests, 98% de cobertura y 102 reglas de análisis estático

- Memoria compartida entre agentes con contexto comprimido entre sesiones y compatibilidad con Claude Code, Codex, Cursor, OpenCode, Gemini, Kiro y Zed bajo licencia MIT

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para estandarizar el comportamiento de tus agentes de código en varios IDEs/CLIs: instala las skills una vez y reutilízalas como infraestructura portable; revisa primero AgentShield sobre tu configuración y secretos antes de conectar el agente a repositorios de producción.
