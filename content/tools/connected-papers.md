# Connected Papers

> Herramienta de exploración académica que genera un grafo visual de artículos relacionados a partir de un paper semilla para descubrir literatura previa y derivada.

**👤 Publicado / Recomendado por:** Precis0x ([@precisox](https://x.com/precisox))

## 💡 ¿Por qué destaca?
- Grafo interactivo de similitud construido sobre la base de datos de Semantic Scholar

- Modos 'Prior works' y 'Derivative works' para rastrear el linaje de una investigación

- Vista de fuerza de conexión entre papers según co-citas y referencias compartidas

- Exportación del grafo y enlaces a cada publicación con sus métricas

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo al arrancar un state-of-the-art o al redactar el related work de un paper técnico, para no perderte las referencias clave de un área.
