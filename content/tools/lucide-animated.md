# Lucide Animated

> Biblioteca open source de más de 350 iconos animados para React construida sobre Motion y Lucide, lista para copiar y pegar en componentes con animaciones suaves.

**👤 Publicado / Recomendado por:** Dev Patel ([@DevDsgn](https://x.com/DevDsgn))

## 💡 ¿Por qué destaca?
- Más de 350 iconos animados optimizados para React

- Construida con Motion y el set de iconos Lucide

- SVG personalizables y listos para copy-paste

- Licencia MIT para uso comercial sin restricciones

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para añadir microinteracciones a botones, menús y estados de carga en interfaces React sin montar un sistema de animación desde cero.
