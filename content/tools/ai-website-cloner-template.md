# ai-website-cloner-template

> Plantilla en TypeScript que clona cualquier sitio web con un solo comando usando agentes de IA, generando un proyecto Next.js listo con Tailwind y shadcn/ui.

**👤 Publicado / Recomendado por:** KATSU ([@katsudev](https://x.com/katsudev))

## 💡 ¿Por qué destaca?
- Clonación de sitios web en un solo comando mediante agentes de código como Claude Code

- Stack Next.js + React + Tailwind CSS + shadcn/ui listo para personalizar

- Incluye skills y estructura de boilerplate para automatizar el reverse-engineering de interfaces

- Más de 38.000 estrellas en GitHub

## 📝 Notas Personales (Segundo Cerebro)
- Úsala para acelerar prototipos o migrar el diseño de una web existente a un proyecto React propio; revisa licencias y derechos del sitio clonado.
