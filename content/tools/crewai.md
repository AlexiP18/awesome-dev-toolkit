# CrewAI

> Framework para orquestar equipos de agentes autónomos con roles y tareas colaborativas en flujos multiagente.

**👤 Publicado / Recomendado por:** Matt Dancho (Business Science) ([@mdancho84](https://x.com/mdancho84))

## 💡 ¿Por qué destaca?
- Define agentes con rol, objetivo y herramientas.

- Orquesta tareas colaborativas entre múltiples agentes.

- Enfocado en equipos de agentes para casos empresariales.

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para automatizar procesos con varios agentes especializados, como investigación, análisis o soporte, validando siempre sus salidas.
