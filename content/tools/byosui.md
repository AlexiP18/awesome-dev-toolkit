# ByosUI

> Una colección de más de 1,105 componentes Shadcn/ui y primitivas desarrolladas internamente, gratuitos y de código abierto, para React y Tailwind CSS, diseñados para acelerar el desarrollo de aplicaciones de producción.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Ofrece más de 1,105 componentes Shadcn/ui y primitivas.

- Gratuito y de código abierto para React y Tailwind CSS.

- Los componentes pueden copiarse y personalizarse directamente o instalarse vía CLI de Shadcn.

- Facilita la creación y envío de aplicaciones a producción más rápidamente.

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para desarrolladores que utilizan Shadcn/ui y React y necesitan una amplia variedad de componentes listos para usar y personalizables para sus proyectos.
