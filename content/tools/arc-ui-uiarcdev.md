# Arc UI (uiarc.dev)

> Biblioteca de componentes React animados listos para ser utilizados en productos modernos, con soporte para shadcn y Next.js, y capacidad de integración con agentes de IA a través de MCP.

**👤 Publicado / Recomendado por:** Houdayfa ([@HoudayfaDesign](https://x.com/HoudayfaDesign))

## 💡 ¿Por qué destaca?
- Componentes UI listos para IA

- Construidos para productos modernos

- Componentes React animados y bloques para shadcn y Next.js

- Integrable con agentes de IA a través del servidor MCP

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para proyectos que buscan una interfaz moderna y futurista, especialmente si planeas integrar capacidades de construcción de UI con agentes de IA.
