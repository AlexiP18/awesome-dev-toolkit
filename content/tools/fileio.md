# file.io

> Servicio de intercambio de archivos con enlaces de un solo uso que se autodestruyen tras la primera descarga.

**👤 Publicado / Recomendado por:** Alejo ([@ecommartinez](https://x.com/ecommartinez))

## 💡 ¿Por qué destaca?
- Enlaces de descarga única

- Caducidad configurable

- API REST sencilla para subidas automatizadas

## 📝 Notas Personales (Segundo Cerebro)
- Perfecto para pasar un build o un log a un compañero sin dejar el archivo expuesto permanentemente en la nube.
