# Novu

> Infraestructura open source para enviar y gestionar notificaciones de usuario por email, SMS y push desde un solo sistema.

## 💡 ¿Por qué destaca?
- Canal de email, SMS y push unificado

- Gestión centralizada de notificaciones de aplicación

- Open source e integrable con backends modernos
