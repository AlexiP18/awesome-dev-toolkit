# Sky-Agent

> Framework ligero en Python para crear un superagente de IA propio con herramientas, memoria persistente y gestión de archivos.

**👤 Publicado / Recomendado por:** Leonard Rodman ([@RodmanAi](https://x.com/RodmanAi))

## 💡 ¿Por qué destaca?
- Framework minimalista para construir agentes con herramientas personalizadas

- Incluye memoria y manejo de archivos como partes nativas del agente

- Código abierto en Python pensado para prototipos rápidos de superagentes

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo si necesitas un agente local sencillo que recuerde contexto y opere archivos, sin la complejidad de plataformas multiagente completas.
