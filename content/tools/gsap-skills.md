# GSAP Skills

> Skills oficiales de GSAP que enseñan a agentes de IA a construir timelines correctas, limpiar animaciones en React y usar los plugins sin errores de API.

**👤 Publicado / Recomendado por:** 露西的百宝箱 ([@Lucy_love_AI](https://x.com/Lucy_love_AI))

## 💡 ¿Por qué destaca?
- Buenas prácticas y patrones comunes de GSAP documentados para el agente

- Enseña limpieza correcta con `useGSAP` y `gsap.context()` en React

- Incluye uso de plugins y límites de uso de la versión gratuita

- Referencias de easing, scroll y animación de SVG

## 📝 Notas Personales (Segundo Cerebro)
- Cárgalo en Claude Code o Cursor antes de pedir animaciones con GSAP: reduce fugas de memoria en React y evita plugins o métodos inexistentes.
