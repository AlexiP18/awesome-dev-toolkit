# Kokoro

> Modelo compacto de texto a voz con pesos abiertos para generar locuciones y narración dentro de pipelines de contenido.

**👤 Publicado / Recomendado por:** Rimsha Bhardwaj ([@heyrimsha](https://x.com/heyrimsha))

## 💡 ¿Por qué destaca?
- Convierte guiones en voiceovers con un modelo TTS open-weight

- Diseñado para integrarse en pipelines de creación de contenido

- Alternativa ligera para narración automatizada sin servicios externos

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para narrar videos, podcasts o demos; revisa la calidad por idioma y la licencia del modelo.
