# REA

> Herramienta de ingeniería inversa asistida por agentes que, a partir del comportamiento observable de una app, reconstruye cómo está implementada incluso sin acceso al código fuente, bajando hasta binarios nativos.

**👤 Publicado / Recomendado por:** niko. ([@nikosolenne](https://x.com/nikosolenne))

## 💡 ¿Por qué destaca?
- Ingeniería inversa guiada por agentes de IA mediante skills y servidores MCP

- Soporte de múltiples stacks: JavaScript/React, Python, Java, Rust, C++ y binarios Android

- CLI en TypeScript que se integra con Claude Code como plugin

- Enfocado en análisis de comportamiento de aplicaciones y auditoría de seguridad

## 📝 Notas Personales (Segundo Cerebro)
- Útil para auditar apps de terceros, analizar dependencias opacas o estudiar implementaciones ajenas; aplícalo solo sobre software propio o con autorización explícita por las implicaciones legales.
