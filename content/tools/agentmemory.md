# agentmemory

> Memoria persistente open source para agentes de codificación IA que conserva actividad y entrega contexto en sesiones posteriores.

**👤 Publicado / Recomendado por:** 𝐍𝐨𝐚𝐡 ([@noahelhadedy](https://x.com/noahelhadedy))

## 💡 ¿Por qué destaca?
- Licencia Apache-2.0 y código abierto

- Almacena la actividad del agente en la máquina local

- Recupera contexto relevante para la siguiente sesión

- Diseñada específicamente para agentes de código IA

## 📝 Notas Personales (Segundo Cerebro)
- Úsala cuando necesites que un agente de codificación recuerde decisiones, archivos y contexto entre sesiones de trabajo.
