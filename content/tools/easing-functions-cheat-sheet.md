# Easing Functions Cheat Sheet

> Hoja de trucos interactiva que muestra visualmente cada curva de easing para animaciones, permitiendo copiar el código CSS correspondiente para movimientos más naturales y fluidos.

**👤 Publicado / Recomendado por:** Aman Singh ([@amananimates](https://x.com/amananimates))

## 💡 ¿Por qué destaca?
- Visualización interactiva de diversas curvas de easing.

- Proporciona el código CSS exacto para cada función de easing.

- Ayuda a los desarrolladores a comprender y aplicar animaciones más naturales.

- Mejora la percepción de calidad en las interfaces de usuario mediante animaciones suaves.

## 📝 Notas Personales (Segundo Cerebro)
- Consulta esta herramienta para elegir la curva de easing adecuada y refinar las animaciones de tus elementos UI, evitando movimientos bruscos o poco profesionales.
