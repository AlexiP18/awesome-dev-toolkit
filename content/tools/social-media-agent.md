# Social Media Agent

> Agente de LangChain que convierte una URL en borradores para X y LinkedIn, permite revisión humana y programa publicaciones.

**👤 Publicado / Recomendado por:** Rimsha Bhardwaj ([@heyrimsha](https://x.com/heyrimsha))

## 💡 ¿Por qué destaca?
- Genera posts para X y LinkedIn a partir de una URL

- Incluye flujo human-in-the-loop para revisar y editar borradores

- Programa publicaciones mediante un agente de IA

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para automatizar la distribución de contenido con control editorial; configura credenciales de las redes y revisa antes de publicar.
