# iLovePDF

> Suite de utilidades para unir, dividir, comprimir, rotar y proteger archivos PDF desde el navegador o su API.

**👤 Publicado / Recomendado por:** Alejo ([@ecommartinez](https://x.com/ecommartinez))

## 💡 ¿Por qué destaca?
- Unión y división por rangos de páginas

- Protección con contraseña y marca de agua

- API de pago para automatizar pipelines

## 📝 Notas Personales (Segundo Cerebro)
- Recomendable para preparar documentación entregable (unir anexos, marcar agua) sin escribir scripts de manipulación PDF.
