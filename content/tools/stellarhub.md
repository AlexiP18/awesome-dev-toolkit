# StellarHub

> App de escritorio gratuita y open source que reúne herramientas de mantenimiento de Windows en un solo lugar; según el tuit, construida con Claude.

**👤 Publicado / Recomendado por:** Ram Maheshwari ([@rammcodes](https://x.com/rammcodes))

## 💡 ¿Por qué destaca?
- Monitoreo de CPU, GPU y RAM, drivers y actualizaciones

- Desinstalación con limpieza de restos, análisis de disco y archivos innecesarios

- Ajustes de privacidad, benchmarks y rutinas de mantenimiento automáticas

## 📝 Notas Personales (Segundo Cerebro)
- Dude... Someone built an all-in-one PC optimizer using Claude. 🪐

It's called StellarHub, and it brings a bunch of Windows maintenance tools together in one desktop app.

You can use it to:

~ Monitor CPU, GPU and RAM. 
~ Manage drivers and software updates. 
~ Uninstall apps and remove leftovers. 
~ Analyze disk space. 
~ Clean unnecessary files. 
~ Manage Windows privacy and security. 
~ Run hardware benchmarks. 
~ Automate maintenance routines.
