# PMTiles

> Proyecto open source de Protomaps que permite servir mapas web pidiendo solo el trozo (tile) que necesitas mediante una API.

**👤 Publicado / Recomendado por:** Miguel Ángel Durán ([@midudev](https://x.com/midudev))

## 💡 ¿Por qué destaca?
- Petición por fragmentos del mapa en lugar de descargar todo

- Gratuito para proyectos no comerciales

- Se puede autoalojar y usar libremente
