# Prime Agent

> Agente de código autónomo open source que se ejecuta sobre un daemon persistente, permitiendo cerrar la terminal y continuar tareas largas con estado, subagentes y memoria entre sesiones.

**👤 Publicado / Recomendado por:** José Siles | AI | Data ([@josesilesdata](https://x.com/josesilesdata))

## 💡 ¿Por qué destaca?
- Arquitectura basada en daemon: la sesión, el estado y los subagentes siguen vivos aunque cierres la terminal o el portátil

- Generación de subagentes reales desde código mediante rlm(...), capaces de ejecutar trabajo en paralelo

- Coordinación directa entre agentes hijo sin necesidad de intervención manual del usuario

- Auto-mejora con /refine: revisa ejecuciones anteriores y guarda lecciones como memoria permanente

- Skills como paquetes ejecutables de Python, con un creador de skills para convertir tareas repetitivas en reutilizables

- Objetivos persistentes con /goal que sobreviven entre sesiones, todo dentro de un IPython persistente

- Licencia MIT e instalación rápida mediante curl; repositorio principal en Rust

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para flujos de coding autónomo de larga duración, tareas que deben continuar tras cerrar la terminal y automatizaciones con subagentes paralelos. Conviene revisar el consumo de recursos y la seguridad de las skills ejecutables antes de dejarlo operando de forma desatendida.
