# lemo-opuscar

> Skill de Claude Code con una colección de 59 estilos cinematográficos generados enteramente mediante código para crear cortometrajes sin modelos de video.

**👤 Publicado / Recomendado por:** Juan ([@7uanF](https://x.com/7uanF))

## 💡 ¿Por qué destaca?
- Incluye 59 estilos prediseñados y soporte para crear estilos cinematográficos propios mediante prompts
- Genera piezas audiovisuales y motion graphics usando código puro con Canvas, Three.js, WebGL y FFmpeg
- Diseñado específicamente como skill/plugin para Claude Code y agentes de IA
- Elimina la dependencia de modelos de difusión de video pesados al programar las animaciones directamente

## 📝 Notas Personales (Segundo Cerebro)
- Excelente complemento para Claude Code enfocado en creativos y desarrolladores que buscan generar visuales y cortometrajes programáticos ligeros y deterministas.
