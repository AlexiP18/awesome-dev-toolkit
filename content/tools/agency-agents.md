# agency-agents

> Repositorio open source (MIT) que empaqueta una agencia completa de IA: decenas de agentes especializados con rol, personalidad, proceso de trabajo y entregables definidos para frontend, backend, IA/ML, DevOps, producto, ventas, legal, QA, marketing, cumplimiento FedRAMP o GIS.

**👤 Publicado / Recomendado por:** PA13L0 ([@Fluyeporlaweb](https://x.com/Fluyeporlaweb))

## 💡 ¿Por qué destaca?
- Más de 166.000 estrellas y 21.000 forks en GitHub con licencia MIT, lo que permite uso comercial y modificación sin restricciones

- Cada agente incluye un system prompt con personalidad propia, flujo de trabajo paso a paso y artefactos entregables concretos (no prompts genéricos)

- Divisiones funcionales completas: ingeniería (frontend, backend, IA/ML, DevOps), negocio (producto, ventas, marketing, legal) y nichos como cumplimiento normativo FedRAMP o sistemas GIS

- Comunidad de ~98 contribuidores que añaden nuevos agentes y divisiones de forma continua, con estructura en Shell y archivos Markdown fáciles de versionar

## 📝 Notas Personales (Segundo Cerebro)
- Clónalo y copia las carpetas de agentes relevantes en tu directorio de subagentes (por ejemplo .claude/agents o equivalente) para orquestar flujos reales de desarrollo: revisión de código QA, scaffolding frontend o auditorías de seguridad con rol y criterios de aceptación predefinidos.
