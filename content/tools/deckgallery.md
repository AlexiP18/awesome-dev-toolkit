# Deck.Gallery

> Galería de presentaciones y decks bellamente diseñados que funciona como referencia de layout, jerarquía y narrativa visual para slides.

**👤 Publicado / Recomendado por:** Tran Mau Tri Tam ✪ ([@tranmautritam](https://x.com/tranmautritam))

## 💡 ¿Por qué destaca?
- Selección de decks con diseño editorial y sistemas de grid sólidos

- Ejemplos de tipografía, gráficos y uso de color en presentaciones

- Inspiración aplicable a presentaciones técnicas y demos de producto

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para preparar pitch decks o charlas técnicas: toma estructuras de slides y patrones de visualización de datos antes de diagramar.
