# Superdesign

> Agente open source de diseño de producto con IA que genera y refina interfaces directamente en un canvas integrado.

**👤 Publicado / Recomendado por:** 0xMarioNawfal ([@RoundtableSpace](https://x.com/RoundtableSpace))

## 💡 ¿Por qué destaca?
- Agente de diseño de producto con IA escrito en TypeScript

- Genera wireframes y pantallas UI dentro de un canvas interactivo

- Proyecto open source con más de 7.500 estrellas en GitHub

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para prototipar pantallas y explorar variantes visuales antes de trasladar el diseño a código de producción.
