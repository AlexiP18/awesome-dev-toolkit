# Have I Been Pwned

> Servicio de consulta de brechas de datos que verifica si un correo o dominio corporativo apareció en filtraciones conocidas y expone una API para automatizar la vigilancia.

**👤 Publicado / Recomendado por:** Precis0x ([@precisox](https://x.com/precisox))

## 💡 ¿Por qué destaca?
- Búsqueda sobre decenas de miles de millones de registros filtrados

- API REST para verificar correos, dominios y contraseñas comprometidas (k-anonymity)

- Monitoreo de dominios corporativos con alertas ante nuevas brechas

- Usado por equipos de seguridad y MSPs para respuesta ante incidentes

## 📝 Notas Personales (Segundo Cerebro)
- Intégralo en los flujos de onboarding y en tu SIEM para bloquear credenciales comprometidas o forzar reseteo de contraseñas tras una filtración conocida.
