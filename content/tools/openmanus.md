# OpenManus

> Agente de IA open source construido en Python por el equipo de MetaGPT que planifica tareas, navega por la web y ejecuta herramientas de forma autónoma, posicionándose como alternativa gratuita a Manus sin invite code.

**👤 Publicado / Recomendado por:** Nix0n ([@UnTalNixon_exe](https://x.com/UnTalNixon_exe))

## 💡 ¿Por qué destaca?
- Compatible con cualquier LLM (OpenAI, Claude, modelos locales, etc.) mediante configuración de proveedor

- Incluye soporte MCP (Model Context Protocol) para conectar herramientas y servidores externos

- Ejecuta tareas complejas end-to-end: SEO audits, investigación web, automatizaciones y análisis de sitios

- Código en Python totalmente abierto y gratuito, sin lista de espera ni invite code

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para orquestar automatizaciones de investigación y scraping con tu propio LLM; revisa la configuración de claves API y proveedores en el repo antes de lanzar tareas largas, y controla el consumo de tokens del modelo elegido.
