# ExpoKit

> Biblioteca de componentes UI animados listos para copiar y pegar en proyectos de Expo y React Native, escritos en TypeScript, que permite elevar el acabado visual de una app móvil sin construir cada pantalla desde cero.

**👤 Publicado / Recomendado por:** Karan ([@itsmeekaran](https://x.com/itsmeekaran))

## 💡 ¿Por qué destaca?
- Componentes animados copy-paste compatibles con Expo y React Native (iOS/Android)

- Incluye CLI propia para añadir componentes al proyecto y el paquete expo-charts para gráficos

- Escrito íntegramente en TypeScript y pensado para personalización directa del código fuente

- Catálogo de UI kit con múltiples componentes reutilizables y tópicos como react-native-ui-library y expo-ui

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para acelerar prototipos o MVPs en Expo: instala la CLI, añade solo los componentes que necesites y personaliza los estilos directamente en tu código en lugar de depender de una librería cerrada.
