# getdesign.ai

> Genera archivos DESIGN.md con referencias de diseño extraídas de sitios reales para que agentes de código (Cursor, Claude Code, Copilot) construyan interfaces web con criterio visual en lugar de estilos genéricos.

**👤 Publicado / Recomendado por:** Viktor Oddy ([@viktoroddy](https://x.com/viktoroddy))

## 💡 ¿Por qué destaca?
- Referencias de diseño reales empaquetadas como archivos .md que el agente de IA puede leer y seguir

- Compatible con coding agents tipo Cursor, Claude Code o Windsurf

- Enfoque en dirección de arte: tipografía, paletas, espaciados y jerarquía visual

- Evita el 'AI slop' visual en webs generadas automáticamente

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo al iniciar un proyecto web generado con IA: coloca el DESIGN.md en la raíz del repo para que el agente respete un sistema visual coherente desde el primer commit.
