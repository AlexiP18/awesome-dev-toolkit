# ppt-master

> Herramienta en Python que convierte un PDF, un Word o un simple tema en una presentación PowerPoint nativa y editable, con formas, transiciones, animaciones, gráficos y narración de audio.

**👤 Publicado / Recomendado por:** niko. ([@nikosolenne](https://x.com/nikosolenne))

## 💡 ¿Por qué destaca?
- Genera .pptx nativo con formas y animaciones reales, no imágenes ni slides planas

- Permite usar tus propias plantillas .pptx como base de diseño corporativo

- Añade gráficos y tablas con datos bajo demanda y narración de audio desde las notas del orador

- Pipeline de agente IA en Python para extraer contenido de documentos de entrada

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para automatizar informes periódicos o decks internos a partir de documentación existente; revisa el resultado final porque plantillas y animaciones personalizadas pueden necesitar ajustes manuales.
