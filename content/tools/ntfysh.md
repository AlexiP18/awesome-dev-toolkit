# ntfy.sh

> Servicio open-source de notificaciones push basado en HTTP que permite enviar alertas a móvil o escritorio mediante peticiones PUT/POST y API REST.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Envío de notificaciones push con una simple llamada HTTP PUT/POST

- Servicio pub-sub ligero con API REST

- Compatible con scripts en cualquier lenguaje o sistema

- Open-source y utilizable sin infraestructura compleja

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para integrar alertas de CI/CD, monitoreo o scripts personales sin montar un sistema de notificaciones propio.
