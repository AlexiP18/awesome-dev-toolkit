# Book of Shapes

> Galería curada de patrones generativos donde puedes descubrir, personalizar y descargar arte algorítmico para usarlo como fondo, textura o punto de partida de un sistema visual.

**👤 Publicado / Recomendado por:** Harshil Tomar ([@Hartdrawss](https://x.com/Hartdrawss))

## 💡 ¿Por qué destaca?
- Catálogo curado de patrones generativos con personalización de parámetros

- Descarga de las piezas generadas para integrarlas en tus diseños

- Enfoque de inspiración y sistema visual más que de librería de componentes

## 📝 Notas Personales (Segundo Cerebro)
- Ideal en la fase de exploración de identidad visual o para crear texturas de fondo; revisa las condiciones de uso de cada pieza antes de incorporarla a un producto comercial.
