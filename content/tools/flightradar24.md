# Flightradar24

> Rastreador global de vuelos en tiempo real que muestra posición, altitud y ruta de aeronaves sobre un mapa, con API de datos para desarrolladores.

**👤 Publicado / Recomendado por:** Precis0x ([@precisox](https://x.com/precisox))

## 💡 ¿Por qué destaca?
- Seguimiento en vivo de miles de aeronaves vía ADS-B con posición y altitud

- Datos de estado de vuelo, retrasos, historial y aeropuertos

- API y SDK de pago (REST y webhooks) para integrar datos de vuelo

- Mapa interactivo con filtros por aerolínea, aeropuerto y tipo de avión

## 📝 Notas Personales (Segundo Cerebro)
- Sirve como fuente de datos reales para demos de visualización geoespacial en tiempo real o para dashboards que necesiten streaming de posiciones sobre un mapa.
