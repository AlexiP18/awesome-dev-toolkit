# Tenuo

> Herramienta para remapear el teclado del Mac con editor visual y capas para atajos y acciones por aplicación, con núcleo gratuito y código abierto bajo licencia MIT.

**👤 Publicado / Recomendado por:** 𝐍𝐨𝐚𝐡 ([@noahelhadedy](https://x.com/noahelhadedy))

## 💡 ¿Por qué destaca?
- Editor visual para remapear teclas del teclado de macOS

- Sistema de capas para atajos y acciones específicas por app

- Código abierto MIT con app core gratuita y mejora Pro opcional de pago único

## 📝 Notas Personales (Segundo Cerebro)
- Configúrala si vienes de otro layout o quieres crear capas tipo programador (Vim, atajos de IDE) sin cambiar de teclado físico; al ser MIT puedes auditar o extender el código.
