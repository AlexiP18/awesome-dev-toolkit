# Matter.js

> Un motor de física 2D de cuerpos rígidos para la web, que permite simular interacciones físicas realistas en aplicaciones y juegos HTML5, ofreciendo detección de colisiones y fuerzas.

**👤 Publicado / Recomendado por:** eigen ([@e1genqq](https://x.com/e1genqq))

## 💡 ¿Por qué destaca?
- Simulación de física 2D de cuerpos rígidos de alto rendimiento

- Ideal para juegos interactivos y efectos visuales basados en física en la web

- Soporta detección de colisiones, fuerzas, articulaciones y restricciones

- Basado en Canvas y JavaScript para una fácil integración web

## 📝 Notas Personales (Segundo Cerebro)
- Empléala para añadir interacciones físicas realistas a elementos de UI, desarrollar pequeños juegos basados en física o crear simulaciones interactivas en el navegador.
