# UI Layouts

> Universo de componentes, efectos y bloques front-end animados con React, Tailwind CSS y Framer Motion.

**👤 Publicado / Recomendado por:** 0xMarioNawfal ([@RoundtableSpace](https://x.com/RoundtableSpace))

## 💡 ¿Por qué destaca?
- Incluye acordeones, tabs animados, modales, mouse trail y spotlight

- Componentes compatibles con shadcn/ui y Tailwind CSS

- Bloques listos para copiar y usar en producción

- Más de 3.800 estrellas en GitHub
