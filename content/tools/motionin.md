# Motionin

> Generador que convierte un único prompt en un sitio web animado, combinando diseño visual y movimiento para producir páginas con transiciones listas para presentar.

**👤 Publicado / Recomendado por:** Bardhyl Bytyqi ([@BardhylBytyqi](https://x.com/BardhylBytyqi))

## 💡 ¿Por qué destaca?
- Un prompt genera una web completa con animaciones

- Enfoque en motion y microinteracciones dentro del layout

- Diseñado para prototipos rápidos de presentación a clientes

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para demos comerciales o pitches donde el movimiento importa más que la lógica de negocio; después reconstruye las partes críticas en tu stack real.
