- Un solo archivo markdown listo para copiar a tu repo o a la configuración de Claude Code

- Cuatro reglas centradas en los fallos típicos de los modelos al escribir código

- Ayuda a frenar la sobre-ingeniería y el código 'vibe-coded' sin verificar

- Sin dependencias, instalación ni configuración adicional
