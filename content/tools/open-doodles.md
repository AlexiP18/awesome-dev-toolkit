# Open Doodles

> Librería de ilustraciones estilo boceto dibujadas a mano, publicadas bajo licencia abierta para uso personal y comercial en productos digitales.

**👤 Publicado / Recomendado por:** 𝐍𝐨𝐚𝐡 ([@noahelhadedy](https://x.com/noahelhadedy))

## 💡 ¿Por qué destaca?
- Set de doodles de personas con trazo manual y estilo desenfadado

- Archivos SVG descargables y editables

- Disponible también como paquete para Figma

- Licencia libre para uso personal y comercial

## 📝 Notas Personales (Segundo Cerebro)
- Perfecta para blogs, newsletters y secciones de contenido donde un estilo humano y relajado encaja mejor que una ilustración corporativa.
