# public-apis

> Catálogo colaborativo en GitHub con cientos de APIs públicas gratuitas organizadas por categoría, indicando autenticación y soporte CORS para prototipar integraciones sin coste.

**👤 Publicado / Recomendado por:** Shruti Codes ([@Shruti_0810](https://x.com/Shruti_0810))

## 💡 ¿Por qué destaca?
- Listado categorizado de APIs con indicadores de auth, HTTPS y CORS

- Actualización continua mediante pull requests de la comunidad

- Filtros por temática: datos, geolocalización, finanzas, clima y más

## 📝 Notas Personales (Segundo Cerebro)
- Consúltala para encontrar endpoints de datos reales en hackathons, MVPs y demos técnicas.
