# ASCII Effect (Componentry)

> Componente React de Componentry que convierte imágenes en arte ASCII responsivo en tiempo real, con animaciones fluidas y un acabado retro listo para incrustar en cualquier interfaz web.

**👤 Publicado / Recomendado por:** Harsh ([@harshjdhv](https://x.com/harshjdhv))

## 💡 ¿Por qué destaca?
- Renderiza imágenes como arte ASCII responsivo que se adapta al tamaño del contenedor

- Incluye variantes 'image', 'flow' y 'glitch' para distintos efectos visuales

- Conversión suave en tiempo real pensada para animaciones continuas sin cortes

- Componente React listo para instalar y usar en proyectos existentes

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para portadas de proyectos, landings creativas o easter eggs visuales; conviene limitar la densidad de caracteres y el framerate en móviles para no penalizar el rendimiento.
