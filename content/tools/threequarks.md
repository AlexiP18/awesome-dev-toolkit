# Three.quarks

> Un sistema de partículas y motor de efectos visuales (VFX) de propósito general para Three.js, ideal para añadir elementos dinámicos como humo, fuego o explosiones a escenas 3D.

**👤 Publicado / Recomendado por:** rachit ([@rachiitgr](https://x.com/rachiitgr))

## 💡 ¿Por qué destaca?
- Sistema de partículas y motor VFX para Three.js

- Permite añadir efectos visuales dinámicos

- Desarrollado en TypeScript con soporte WebGL

## 📝 Notas Personales (Segundo Cerebro)
- Perfecto para desarrolladores que buscan integrar efectos de partículas y VFX en sus proyectos Three.js de manera eficiente.
