# Context

> Context.dev es una API de web scraping diseñada específicamente para agentes de IA, que permite raspar URLs, buscar en la web en tiempo real y rastrear sitios para extraer datos estructurados listos para LLM.

**👤 Publicado / Recomendado por:** Yash ([@dewyashtwts](https://x.com/dewyashtwts))

## 💡 ¿Por qué destaca?
- Scrape cualquier URL en formato Markdown listo para LLM

- Busca en la web en vivo y realiza rastreo de sitios completos

- Extrae datos estructurados a través de una API REST

- Diseñado para la integración con agentes de IA

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para dotar a los agentes de IA con capacidades avanzadas de recolección de información web para análisis o generación de contenido.
