# LangChain

> Framework de código abierto para construir aplicaciones LLM con cadenas, herramientas, memoria y agentes en Python y JavaScript.

**👤 Publicado / Recomendado por:** Matt Dancho (Business Science) ([@mdancho84](https://x.com/mdancho84))

## 💡 ¿Por qué destaca?
- Abstracciones para cadenas, prompts, herramientas y memoria en aplicaciones LLM.

- Integraciones con modelos, bases vectoriales y APIs externas.

- Base para flujos de agentes y aplicaciones de producción.
