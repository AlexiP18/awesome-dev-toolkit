# OpenTUI

> Librería para construir interfaces de usuario de terminal con TypeScript, React o Solid sobre un renderizador nativo escrito en Zig, permitiendo crear TUIs modernas y de alto rendimiento.

**👤 Publicado / Recomendado por:** Tran Mau Tri Tam ✪ ([@tranmautritam](https://x.com/tranmautritam))

## 💡 ¿Por qué destaca?
- API declarativa compatible con TypeScript, React y Solid

- Renderizador nativo en Zig para dibujado eficiente en terminal

- Compatible con toolchains JS existentes (npm, bundlers, tipado)

## 📝 Notas Personales (Segundo Cerebro)
- Úsala para CLIs interactivas, dashboards de terminal o herramientas de desarrollo internas; verifica el soporte de tu terminal para secuencias ANSI avanzadas.
