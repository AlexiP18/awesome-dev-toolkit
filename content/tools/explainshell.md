# ExplainShell

> Descompone un comando de shell y muestra, opción por opción, la explicación extraída de las man pages oficiales.

**👤 Publicado / Recomendado por:** Alejo ([@ecommartinez](https://x.com/ecommartinez))

## 💡 ¿Por qué destaca?
- Desglose visual de cada flag y argumento

- Fuente directa de las man pages de Linux

- Comparte resultados mediante URL con el comando incrustado

## 📝 Notas Personales (Segundo Cerebro)
- Perfecto para auditar comandos peligrosos (rm, dd, find) pegados de internet antes de ejecutarlos en tu máquina.
