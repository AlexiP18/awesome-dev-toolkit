# Aura Build

> Herramienta gratuita que analiza una URL y genera un sistema de diseño con colores, tipografías y layouts, facilitando replicar o inspirarse en el estilo visual de cualquier web.

**👤 Publicado / Recomendado por:** ares. ([@aresotik](https://x.com/aresotik))

## 💡 ¿Por qué destaca?
- Entrada mediante una URL pública de cualquier sitio web

- Extrae paleta de colores, fuentes y estructuras de layout

- Genera un sistema de diseño reutilizable para frontend y UI

- Uso gratuito y orientado a prototipado rápido

## 📝 Notas Personales (Segundo Cerebro)
- Úsala para auditar el estilo visual de sitios de referencia, extraer design tokens iniciales o acelerar la creación de un sistema de diseño coherente en proyectos frontend.
