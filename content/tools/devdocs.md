- Developers, these 7 websites deserve a spot in your bookmarks. 👀

1. https://roadmap.sh — Step-by-step learning paths for developers.

2. https://regex101.com — Test and understand regular expressions.

3. https://transform.tools — Convert JSON, TypeScript, CSS, and more.

4. https://excalidraw.com — Draw system architectures and technical diagrams.

5. https://bundlephobia.com — Check the size of npm packages before installing them.

6. https://sqlbolt.com — Learn SQL through interactive exercises.
