# ManimGX

> Motor de animación 3D en Python de código abierto, construido sobre el ecosistema Manim, para generar vídeos matemáticos y explicaciones visuales de algoritmos con un rendimiento muy superior a Blender.

**👤 Publicado / Recomendado por:** Brais Moure ([@MoureDev](https://x.com/MoureDev))

## 💡 ¿Por qué destaca?
- Escrito en Python y pensado para orquestarse mediante agentes de IA que generan las animaciones de forma programática

- Renderizado de vídeo 3D y matemático (fórmulas, geometría, grafos) significativamente más rápido que Blender

- Enfoque 'engine for agents': flujo automatizable para producir vídeos explicativos de algoritmos sin edición manual

- Vinculado al ecosistema Academa, con vídeos de divulgación técnica generados y comentados por IA

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo cuando necesites producir visualizaciones didácticas de algoritmos, grafos o demostraciones matemáticas dentro de un pipeline automatizado (por ejemplo, invocado desde un agente LLM); conviene revisar la documentación oficial de Manim para las primitivas 3D antes de migrar escenas existentes desde Blender.
