# Fincept Terminal

> Terminal de análisis financiero de escritorio open source, planteado como alternativa libre a Bloomberg Terminal, con datos de mercado, indicadores y herramientas de análisis para desarrolladores e inversores.

**👤 Publicado / Recomendado por:** yuulia ✟ ([@yuliaisc](https://x.com/yuliaisc))

## 💡 ¿Por qué destaca?
- Aplicación de escritorio multiplataforma con paneles de cotizaciones e indicadores técnicos

- Integración de fuentes de datos de mercado y análisis fundamental/técnico

- Código abierto, extensible con módulos y scripts propios

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo si quieres construir o extender tu propio dashboard financiero sin pagar licencias de terminales propietarias; verifica las fuentes de datos que conectes por sus límites de uso.
