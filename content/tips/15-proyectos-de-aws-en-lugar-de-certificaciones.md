# 💡 15 proyectos de AWS en lugar de certificaciones

> Hoja de ruta de 15 proyectos prácticos de AWS por nivel para demostrar habilidades en lugar de acumular certificaciones.

**👤 Publicado / Recomendado por:** YourCloudDude | AWS & Python ([@yourclouddude](https://x.com/yourclouddude))

## 📌 Puntos Clave & Pasos del Consejo
- Principiante: S3 + CloudFront, EC2, VPC, API Gateway + Lambda + DynamoDB, subidas con URLs prefirmadas

- Intermedio: pipelines con Lambda, ALB + Auto Scaling, 3 capas con RDS, CloudWatch + SNS, CI/CD con CodePipeline y ECS

- Avanzado: ECS + Fargate, SQS event-driven, S3 + Glue + Athena, Cognito y alta disponibilidad multi-AZ

## 📝 Aplicación Práctica & Contexto
- STOP COLLECTING AWS CERTIFICATIONS. BUILD THESE 15 PROJECTS INSTEAD. ☁️

BEGINNER LEVEL

1. Static Website
→ S3 + CloudFront
Learn: Hosting, CDN, HTTPS

2. EC2 Web Server
→ EC2 + EBS + Security Groups
Learn: Linux, compute, networking

3. Secure Cloud Network
→ VPC + Subnets + NAT Gateway
Learn: Routing, isolation, security

4. Serverless REST API
→ API Gateway + Lambda + DynamoDB
Learn: APIs, serverless, NoSQL

5. File Upload Application
→ S3 + Presigned URLs
Learn: Secure uploads, object storage

INTERMEDIATE LEVEL

6. Image Processing Pipeline
→ S3 + Lambda
Learn: Events, automation, triggers

7. Scalable Web Application
→ ALB + EC2 Auto Scaling
Learn: Load balancing, scalability

8. 3-Tier Web Architecture
→ ALB + EC2 + RDS
Learn: Application architecture, databases

9. Cloud Monitoring System
→ CloudWatch + SNS
Learn: Metrics, logs, alerts

10. CI/CD Deployment Pipeline
→ CodePipeline + CodeBuild + ECS
Learn: Automated builds and deployment

ADVANCED LEVEL

11. Containerized Application
→ ECS + Fargate + ECR
Learn: Docker, containers, orchestration

12. Event-Driven Order System
→ SQS + Lambda + DynamoDB
Learn: Queues, retries, decoupling

13. Data Analytics Pipeline
→ S3 + Glue + Athena
Learn: ETL, SQL, data lakes

14. Secure User Authentication
→ Cognito + API Gateway + Lambda
Learn: Authentication, JWT, API security

15. Highly Available Web App
→ Route 53 + ALB + Auto Scaling + RDS
Learn: Multi-AZ design, failover, resilience

HERE'S THE DIFFERENCE:

A certification shows what you've studied.

A working project shows what you can BUILD.

Don't just memorize AWS services.

→ DEPLOY applications.
→ SECURE infrastructure.
→ DEBUG failures.
→ DOCUMENT architectures.

Your GitHub should prove your AWS skills.
