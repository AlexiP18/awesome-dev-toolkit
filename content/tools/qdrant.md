# Qdrant

> Base de datos vectorial de alto rendimiento escrita en Rust para búsqueda por similitud y recuperación semántica a escala.

**👤 Publicado / Recomendado por:** Matt Dancho (Business Science) ([@mdancho84](https://x.com/mdancho84))

## 💡 ¿Por qué destaca?
- Motor de búsqueda vectorial escalable y de alto rendimiento.

- API y despliegue cloud gestionado en Qdrant Cloud.

- Escrito en Rust para eficiencia y baja latencia.

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para almacenar embeddings en sistemas RAG y motores de recomendación; considera Qdrant Cloud si no quieres gestionar infraestructura.
