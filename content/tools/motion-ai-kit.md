# Motion AI Kit

> Plugin y conjunto de reglas oficiales de Motion para asistentes de código como Cursor o Claude Code, con documentación y guías de animación de interfaces listas para el agente.

**👤 Publicado / Recomendado por:** 露西的百宝箱 ([@Lucy_love_AI](https://x.com/Lucy_love_AI))

## 💡 ¿Por qué destaca?
- Contexto oficial de la API de Motion inyectado en el asistente de código

- Patrones correctos de animación de layout, gestos y transiciones

- Evita el uso de APIs obsoletas de framer-motion en el código generado

## 📝 Notas Personales (Segundo Cerebro)
- Instálalo si trabajas con Motion en Cursor o Claude Code: el agente generará animaciones válidas y coherentes con la versión actual de la librería, sin alucinar props.
