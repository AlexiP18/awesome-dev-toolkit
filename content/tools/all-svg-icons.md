# All SVG Icons

> Buscador de más de 459.000 iconos SVG gratuitos que permite copiar el código SVG o descargarlos en PNG, SVG, JSX o Base64 para integrarlos directamente en proyectos.

**👤 Publicado / Recomendado por:** Dev Patel ([@DevDsgn](https://x.com/DevDsgn))

## 💡 ¿Por qué destaca?
- Más de 459.000 iconos SVG indexados y buscables

- Exportación como SVG, PNG, JSX o Base64

- Copia directa del código SVG al portapapeles

- Alternativa a Flaticon, Iconmonstr y SVG Repo

## 📝 Notas Personales (Segundo Cerebro)
- Muy práctico para encontrar rápidamente un icono suelto y pegarlo como JSX en React, o como Base64 en estilos y prototipos sin dependencias externas.
