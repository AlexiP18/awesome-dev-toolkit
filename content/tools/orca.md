# Orca

> Entorno de desarrollo de agentes (ADE) open source y multiplataforma que ejecuta en paralelo agentes CLI como Claude Code, Codex, Gemini o Cursor CLI aislados en worktrees de Git.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Ejecución paralela de múltiples agentes CLI (Claude Code, Codex, Gemini, Cursor CLI) en worktrees aislados

- Alternativa open source y gratuita a los IDEs tradicionales para trabajo con agentes de código

- Multiplataforma y con actualizaciones de funcionalidades diarias

## 📝 Notas Personales (Segundo Cerebro)
- Ideal cuando quieres lanzar varias tareas de codificación con IA simultáneamente sin que se pisen los cambios; el aislamiento por worktree facilita revisar y fusionar cada rama de forma limpia.
