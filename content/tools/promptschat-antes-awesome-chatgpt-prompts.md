# prompts.chat (antes Awesome ChatGPT Prompts)

> Biblioteca open source de prompts seleccionados y listos para usar con ChatGPT, Claude, Gemini y otros LLMs, con más de 167k estrellas en GitHub y disponible como CLI, servidor MCP o plugin de Claude Code.

**👤 Publicado / Recomendado por:** Nona ([@Nona_xai](https://x.com/Nona_xai))

## 💡 ¿Por qué destaca?
- Colección curada de prompts comunitarios compatible con ChatGPT, Claude, Gemini y otros modelos de lenguaje

- Se puede ejecutar como CLI, como servidor MCP (Model Context Protocol) o como plugin de Claude Code

- Autoalojable: permite desplegar una instancia privada con branding y autenticación personalizados para tu organización

- Proyecto 100% gratuito y open source (Next.js/TypeScript/MDX) con más de 167k estrellas y citado por Harvard y Columbia

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo como catálogo de referencia para acelerar la creación de prompts de producción, o autoalójalo con Docker en tu organización si necesitas privacidad total; conéctalo vía MCP para que tus agentes de código reutilicen los prompts directamente desde el editor.
