# Gradientool

> Generador web de gradientes CSS con salidas prácticamente infinitas: ajustas colores, ángulos y paradas y obtienes el código listo para pegar en tu hoja de estilos sin escribir sintaxis a mano.

**👤 Publicado / Recomendado por:** Harshil Tomar ([@Hartdrawss](https://x.com/Hartdrawss))

## 💡 ¿Por qué destaca?
- Generación de gradientes únicos con resultados ilimitados a partir de la misma paleta

- Salida directa de CSS copiable para usar en cualquier proyecto web o framework

- Interfaz ligera en el navegador, sin registro ni dependencias

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo cuando necesites fondos, hero sections o degradados de acento en landing pages y quieras pasar del diseño al CSS en segundos en lugar de calcular paradas manualmente.
