# Browser Use

> Librería open source en Python que permite a agentes de IA controlar un navegador real mediante instrucciones en lenguaje natural, sin Selenium ni selectores CSS frágiles, para automatizar tareas web de principio a fin.

**👤 Publicado / Recomendado por:** rob. ([@robiartec](https://x.com/robiartec))

## 💡 ¿Por qué destaca?
- Ejecuta instrucciones en lenguaje natural: navega, rellena formularios, extrae datos y completa flujos completos de forma autónoma

- Compatible con cualquier LLM (Claude, GPT, Gemini, DeepSeek) y construida sobre Playwright/CDP con soporte de navegadores sigilosos y headless

- 89.1% de éxito en un benchmark de 100 tareas reales, superando a herramientas comerciales de pago

- Licencia MIT, más de 120.000 estrellas en GitHub, 319 contribuyentes y certificación SOC 2, con despliegue en producción en equipos de Google, Amazon, Anthropic, Stripe y Shopify

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para automatizar scraping dinámico, pruebas E2E tolerantes a cambios de DOM, rellenado de formularios y flujos RPA donde los selectores tradicionales se rompen; conviene instalar vía pip con un LLM configurado y usar Browser Use Cloud si se necesita sigilo o escalado headless.
