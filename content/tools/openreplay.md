# OpenReplay

> Herramienta self-hosted de session replay para observar cómo los usuarios interactúan con la app y dónde abandonan.

**👤 Publicado / Recomendado por:** Hasan Toor ([@hasantoxr](https://x.com/hasantoxr))

## 💡 ¿Por qué destaca?
- Grabación y reproducción de sesiones de usuario

- Despliegue autoalojado para control de datos

- Analítica de embudos y puntos de abandono

## 📝 Notas Personales (Segundo Cerebro)
- Úsala para depurar problemas de UX y entender flujos reales sin depender de terceros.
