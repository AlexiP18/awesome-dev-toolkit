# GodUI

> Colección de componentes de interfaz de usuario animados de código abierto, construidos con React, TypeScript, Tailwind CSS, Motion y shadcn/ui para interfaces web modernas.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Colección de componentes UI con animaciones.

- Basado en React, TypeScript y Tailwind CSS.

- Integra shadcn/ui para una experiencia de desarrollo cohesionada.

- Ideal para interfaces modernas y dinámicas.
