# Vault - Ransom Note Effect

> Efecto visual de nota de rescate (ransom note) para la web que se puede previsualizar, copiar e instalar como skill de agente con un solo comando.

**👤 Publicado / Recomendado por:** Arlan Marat ([@arlanmarat](https://x.com/arlanmarat))

## 💡 ¿Por qué destaca?
- Genera tipografía recortada estilo ransom note para landing pages, heroes o secciones experimentales

- Incluye código copiable y visuales instalables de forma independiente como agent skills

- Instalación mediante un único comando desde el catálogo Vault

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para dar un toque editorial o experimental a secciones concretas; revisa el contraste y la legibilidad si aplicas el efecto en textos principales.
