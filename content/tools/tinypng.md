# TinyPNG

> Optimizador de imágenes online con compresión lossy inteligente para PNG, JPEG y WebP que reduce el peso sin pérdida perceptible de calidad.

**👤 Publicado / Recomendado por:** Precis0x ([@precisox](https://x.com/precisox))

## 💡 ¿Por qué destaca?
- Compresión inteligente de PNG, JPEG y WebP manteniendo transparencia

- API y plugins oficiales para webpack, Photoshop y flujos CI/CD

- Reducción típica del 50-80% del tamaño de archivo

- Procesamiento por lotes y soporte de hasta 5 MB por archivo en el plan gratuito

## 📝 Notas Personales (Segundo Cerebro)
- Automatízalo en el build con su plugin de npm/webpack para que los assets de producción salgan siempre comprimidos y mejorar el LCP y el Core Web Vitals.
