# Animated Buttons Colorion

> Catálogo open-source de botones CSS animados listos para copiar, con efectos hover y transiciones que aportan interactividad a interfaces web.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Botones animados implementados únicamente con CSS

- Código copiable y adaptable a cualquier proyecto

- Efectos hover, clic y transiciones predefinidas

- Colección gratuita y open-source de Colorion

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para prototipar quickly microinteracciones en formularios, CTAs y componentes de navegación sin añadir dependencias JavaScript.
