# SVGO

> Optimizador de SVG para Node.js y CLI que elimina metadatos, simplifica paths y reduce el tamaño de los archivos antes de animarlos o publicarlos.

**👤 Publicado / Recomendado por:** 露西的百宝箱 ([@Lucy_love_AI](https://x.com/Lucy_love_AI))

## 💡 ¿Por qué destaca?
- CLI `svgo archivo.svg -o salida.svg` y uso programático en Node.js

- Plugins configurables: `removeViewBox`, `convertPathData`, `cleanupIds`, etc.

- Integrable en scripts de build, Vite/Webpack o CI

- Salida determinista apta para diffs y control de versiones

## 📝 Notas Personales (Segundo Cerebro)
- Pásalo siempre por los SVG exportados de Figma/Illustrator antes de animar con GSAP o Anime.js: menos nodos y colores normalizados evitan saltos raros en el morphing.
