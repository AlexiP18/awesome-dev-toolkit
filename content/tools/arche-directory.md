# Arche Directory

> Directorio curado de más de 500 diseños de sitios web, incluyendo landing pages, portafolios y sitios de estudio, que sirven como inspiración para comenzar proyectos sin una página en blanco.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Más de 500 diseños web seleccionados manualmente.

- Incluye ejemplos de landing pages, portafolios y sitios de estudio.

- Muestra detalles como tipografía, paleta de colores y secciones de cada diseño.

- Útil para desarrolladores y diseñadores en busca de inspiración y referencias.

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para cuando necesitas inspiración para el diseño de tu próximo proyecto web o quieres entender las tendencias actuales en diseño de interfaces y experiencias de usuario.
