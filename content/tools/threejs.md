# Three.js

> Librería JavaScript de referencia para crear escenas 3D en el navegador con WebGL/WebGPU: cámaras, luces, materiales, geometrías y animación por frame.

**👤 Publicado / Recomendado por:** 露西的百宝箱 ([@Lucy_love_AI](https://x.com/Lucy_love_AI))

## 💡 ¿Por qué destaca?
- Abstracción completa de WebGL: escena, cámara, renderer y ciclo de render

- Catálogo amplio de materiales, luces, sombras y postprocesado

- Cargadores de glTF, OBJ, FBX y texturas, más control de animaciones esqueléticas

- Ecosistema enorme de ejemplos, addons y documentación

## 📝 Notas Personales (Segundo Cerebro)
- Es la base para visores de producto 3D, configuradores o experiencias inmersivas; en React normalmente se consume a través de React Three Fiber.
