# opencodex

> Proxy universal de proveedores LLM que permite usar Claude, Gemini, Grok, DeepSeek u Ollama dentro de OpenAI Codex y Claude Code.

**👤 Publicado / Recomendado por:** brenz. ([@brenzhills](https://x.com/brenzhills))

## 💡 ¿Por qué destaca?
- Actúa como pasarela entre Codex CLI/App/SDK y Claude Code con múltiples backends

- Soporta Anthropic, OpenAI, Gemini, Grok, DeepSeek, Ollama y OpenRouter

- Implementado en TypeScript y orientado a entornos de desarrollo con agentes

## 📝 Notas Personales (Segundo Cerebro)
- Configúralo cuando quieras probar modelos alternativos en tus flujos de Claude Code o Codex sin cambiar de cliente.
