# Remotion Skills

> Paquete de skills oficiales que enseña a agentes de código como Claude Code el flujo correcto para estructurar, animar y renderizar proyectos de vídeo con Remotion.

**👤 Publicado / Recomendado por:** 露西的百宝箱 ([@Lucy_love_AI](https://x.com/Lucy_love_AI))

## 💡 ¿Por qué destaca?
- Instrucciones y patrones oficiales del equipo de Remotion para agentes de IA

- Cubre el ciclo brief → composición → animación → render dentro de un proyecto Remotion

- Reduce errores típicos de los agentes al usar APIs de vídeo y timing de frames

## 📝 Notas Personales (Segundo Cerebro)
- Añádelo al contexto de tu agente de código cuando vayas a generar o modificar composiciones de Remotion, para que respete convenciones y APIs actuales en lugar de improvisar.
