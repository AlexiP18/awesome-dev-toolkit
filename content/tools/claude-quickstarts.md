# claude-quickstarts

> Colección de ejemplos para empezar a construir aplicaciones con Claude a partir de plantillas ejecutables.

**👤 Publicado / Recomendado por:** そう@『n8nの教科書』マイナビ出版 10/22発売 ([@so_ainsight](https://x.com/so_ainsight))

## 💡 ¿Por qué destaca?
- Plantillas que funcionan desde el inicio

- Base para prototipar apps con Claude

## 📝 Notas Personales (Segundo Cerebro)
- 今週GitHubで急上昇したAIリポジトリ10選：

1. security-audit-skill
AIエージェントにコードの安全点検を何段階かに分けて任せられる。見つかった問題は裏取り済みの形で返ってくる。
https://github.com/cloudflare/security-audit-skill

2. astryx
画面デザインの部品をまとめたオープンソースの土台。思いどおりに作り替えられ、AIエージェントからも扱える。
https://github.com/meta/astryx

3. Agent Skills（anthropics）
新しい手順をAIエージェントに覚えさせる部品を集めた公開セット。必要な力を後から足していける。
https://github.com/anthropics/skills

4. agent-browser
ブラウザ操作そのものをAIエージェントに任せられる道具。ページを開いて入力やクリックを代わりに進める。
https://github.com/vercel-labs/agent-browser

5. graphify
プログラムや資料のまとまりが、関係をたどれる地図に変わる。AIエージェントがどこに何があるかを問い合わせられる。
https://github.com/Graphify-Labs/graphify

6. claude-mem
AIエージェントとのやり取りの記憶を残し、次の会話へ引き継げる。前回を覚えた状態で続きから始められる。
https://github.com/thedotmack/claude-mem

7. Claude-Code-Game-Studios
Claude Code をまるごとゲーム開発チームに変えられる。役割の違うエージェントたちが連携して制作を進める。
https://github.com/Donchitos/Claude-Code-Game-Studios

8. herdr
コードを書くAIエージェントを動かすための土台となる環境。接続が切れても作業中の端末は消えず、再接続すると元の配置に戻る。
https://github.com/herdrdev/herdr

9. gstack
Garry Tan の Claude Code 設定をそのまま取り込める。経営から品質管理まで、役割ごとの道具一式がそろう。
https://github.com/garrytan/gstack

10. claude-quickstarts
Claude を使ったアプリ作りをすぐ始められるサンプル集。動かせる形のひな型から試して形にできる。
https://github.com/anthropics/claude-quickstarts

10件の詳細はリプ欄へ👇
