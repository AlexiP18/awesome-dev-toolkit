# Viora UI

> Colección de primitivas React, componentes de UI con movimiento y plantillas Next.js construidas con Tailwind CSS y Framer Motion para interfaces modernas y animadas.

**👤 Publicado / Recomendado por:** KASUN ([@kasuncfdo](https://x.com/kasuncfdo))

## 💡 ¿Por qué destaca?
- Primitivas y componentes React con animaciones basadas en Framer Motion

- Plantillas para Next.js listas para reutilizar

- Estilos gestionados con Tailwind CSS, fáciles de personalizar por tokens

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para proyectos Next.js donde necesitas microinteracciones y transiciones pulidas sin escribir animaciones desde cero; revisa las plantillas para arrancar un sitio con estética cuidada.
