# Reactive Resume

> Constructor de currículums open source en TypeScript y React con editor visual en tiempo real, plantillas y exportación a PDF, self-hosteable y sin venta de datos.

**👤 Publicado / Recomendado por:** Sentient ([@sentient_agency](https://x.com/sentient_agency))

## 💡 ¿Por qué destaca?
- Editor en tiempo real construido con React y TypeScript

- Múltiples plantillas con control de tipografía, colores y disposición

- Exportación a PDF y datos portables en JSON

- Autenticación, base de datos y almacenamiento self-hosted con Docker

## 📝 Notas Personales (Segundo Cerebro)
- Despliégalo en tu VPS para mantener tu CV versionado y privado; también sirve como referencia de arquitectura React + API.
