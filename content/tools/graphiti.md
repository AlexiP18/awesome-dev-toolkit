# Graphiti

> Librería Python para construir grafos de conocimiento temporales que permiten a los agentes de IA recordar información cambiante en el tiempo.

**👤 Publicado / Recomendado por:** Shruti Codes ([@Shruti_0810](https://x.com/Shruti_0810))

## 💡 ¿Por qué destaca?
- Grafos temporales que modelan la evolución de entidades y relaciones

- Integración con agentes y pipelines RAG

- API en Python para consultas y actualizaciones incrementales

## 📝 Notas Personales (Segundo Cerebro)
- Empléala cuando un agente necesite memoria histórica y relaciones entre entidades que cambian con el tiempo.
