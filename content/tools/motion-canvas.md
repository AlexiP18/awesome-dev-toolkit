# Motion Canvas

> Herramienta en TypeScript para crear vídeos de explicación, gráficos animados y presentaciones técnicas escribiendo la animación como código con previsualización en tiempo real.

**👤 Publicado / Recomendado por:** 露西的百宝箱 ([@Lucy_love_AI](https://x.com/Lucy_love_AI))

## 💡 ¿Por qué destaca?
- Animaciones declarativas con generadores y `yield` de TypeScript para controlar el tiempo

- Editor visual con previsualización en vivo y línea de tiempo

- Ideal para diagramas técnicos, gráficos y explicaciones paso a paso

- Exportación a vídeo mediante FFmpeg

## 📝 Notas Personales (Segundo Cerebro)
- Perfecto para documentar arquitecturas, explicar algoritmos o generar clips de release notes animados con control total del timing desde el editor.
