# Iconly

> Biblioteca de iconos de alta calidad con estilos consistentes y exportación vectorial, pensada para mantener coherencia visual en interfaces y design systems.

**👤 Publicado / Recomendado por:** Bardhyl Bytyqi ([@BardhylBytyqi](https://x.com/BardhylBytyqi))

## 💡 ¿Por qué destaca?
- Set amplio de iconos en SVG escalables y editables

- Estilos unificados de trazo y relleno para mezclar sin ruido visual

- Adecuado para Figma y para importar directamente en componentes web

## 📝 Notas Personales (Segundo Cerebro)
- Descarga el set completo en un mismo estilo antes de empezar el proyecto para evitar mezclar grosores de trazo entre pantallas.
