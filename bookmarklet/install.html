📌 Bookmarklet: 1-Clic Guardar en Toolkit

Para guardar cualquier tweet de X (Twitter) con un solo clic mientras navegas (compatible con la política de seguridad CSP de X):

  1. Asegúrate de tener visible la Barra de marcadores en tu navegador (Ctrl + Shift + B o Cmd + Shift + B).
  2. Si tenías una versión anterior del marcador, bórrala primero.
  3. Arrastra el siguiente botón azul hacia tu barra de marcadores:
⚡ Guardar en Dev Toolkit
💡 ¿Cómo funciona con hilos? Si estás viendo un hilo de tweets (como un tutorial o serie de prompts), el bookmarklet detecta automáticamente todos los tweets consecutivos del mismo autor, auto-expande el texto truncado y los guarda juntos como un solo recurso en tu catálogo.
