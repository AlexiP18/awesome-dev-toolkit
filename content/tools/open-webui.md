# Open WebUI

> Interfaz web autoalojada y amigable para gestionar modelos, herramientas, documentos y flujos de agentes con soporte para Ollama y APIs OpenAI.

**👤 Publicado / Recomendado por:** Shruti Codes ([@Shruti_0810](https://x.com/Shruti_0810))

## 💡 ¿Por qué destaca?
- UI self-hosted para LLMs con integración Ollama y OpenAI

- Soporte de RAG, herramientas, MCP y flujos de agentes

- Frontend en Svelte con despliegue sencillo en contenedores

## 📝 Notas Personales (Segundo Cerebro)
- Úsala para montar un portal interno de IA generativa con control total sobre datos y modelos.
