# LLM App (serviette)

> Servidor RAG no-code construido sobre Pathway que mantiene las respuestas sincronizadas con tus documentos y funciona con 8 bases de datos vectoriales.

**👤 Publicado / Recomendado por:** Dhairya Karekar ([@dkare1009](https://x.com/dkare1009))

## 💡 ¿Por qué destaca?
- Servidor RAG no-code con datos en tiempo real

- Compatible con 8 bases de datos vectoriales (pgvector, Qdrant, Pinecone, Weaviate, etc.)

- Sincroniza las respuestas con los documentos automáticamente

- Orientado a enterprise search y pipelines RAG self-hosted

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para montar un RAG self-hosted rápido sin escribir mucho código; revisa la integración con tu vector DB.
