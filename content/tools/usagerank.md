# UsageRank

> Una plataforma para compartir y clasificar el uso de modelos de IA como Claude Code y Codex, permitiendo a los desarrolladores comparar su consumo de tokens y gastos en un leaderboard público.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Clasificación pública de desarrolladores por uso de IA.

- Monitorea el uso de tokens y el dinero gastado en Claude Code y Codex.

- Ofrece un leaderboard para comparar la actividad de desarrollo con IA.

- Herramienta de analítica para el consumo de recursos de agentes de IA.

## 📝 Notas Personales (Segundo Cerebro)
- Utiliza esta herramienta para visualizar y optimizar tu consumo de recursos en proyectos que emplean asistentes de codificación basados en IA como Claude Code y Codex.
