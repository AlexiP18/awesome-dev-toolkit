# useAnimations

> Biblioteca de 300 microanimaciones gratuitas para UI con iconos animados compatibles con React, shadcn/ui y Lottie, incluyendo estados hover, click y loop.

**👤 Publicado / Recomendado por:** Dev Patel ([@DevDsgn](https://x.com/DevDsgn))

## 💡 ¿Por qué destaca?
- 300 microanimaciones listas para interfaces de usuario

- Soporte para React, shadcn/ui y Lottie

- Animaciones con hover, click y loop preconfigurados

- Licencia MIT para integración en proyectos comerciales

## 📝 Notas Personales (Segundo Cerebro)
- Recomendada para añadir feedback visual sutil en componentes shadcn/ui o React, especialmente en botones, tarjetas y estados de interacción.
