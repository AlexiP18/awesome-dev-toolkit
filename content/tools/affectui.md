# affectUI

> Biblioteca de componentes React, pantallas y bloques listos para productos de IA y SaaS, con archivos únicos sin dependencias externas.

**👤 Publicado / Recomendado por:** Nero ([@neropursue](https://x.com/neropursue))

## 💡 ¿Por qué destaca?
- Componentes React entregados como un solo archivo sin dependencias, fáciles de copiar y pegar

- Compatible con flujos de agentes de código como Claude, Cursor o v0 para generación automática

- Catálogo de screens y blocks orientados a dashboards y landings de productos de IA

- Diseño 'agent-ready' pensado para que un LLM integre la UI directamente en el proyecto

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo cuando necesites montar rápidamente una landing o dashboard de un producto de IA sin arrastrar un design system completo; puedes pedir a Cursor o v0 que añada los componentes directamente.
