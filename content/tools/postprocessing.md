# postprocessing

> Una biblioteca de postprocesado para Three.js que añade efectos visuales avanzados como bloom, profundidad de campo y etalonaje para mejorar la calidad y el estilo de las escenas 3D.

**👤 Publicado / Recomendado por:** rachit ([@rachiitgr](https://x.com/rachiitgr))

## 💡 ¿Por qué destaca?
- Biblioteca de postprocesado para Three.js

- Incluye efectos visuales como bloom, profundidad de campo

- Mejora el etalonaje y la apariencia final de las escenas 3D

## 📝 Notas Personales (Segundo Cerebro)
- Aplica efectos de postprocesado para dar un toque cinematográfico o estilizado a tus visualizaciones 3D en la web.
