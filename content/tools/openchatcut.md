# OpenChatCut

> Un editor de video conversacional de código abierto y local-first que permite editar videos charlando con IA para ajustar clips, transiciones, subtítulos, efectos y audio, manteniendo la línea de tiempo totalmente editable.

**👤 Publicado / Recomendado por:** Rimsha Bhardwaj ([@heyrimsha](https://x.com/heyrimsha))

## 💡 ¿Por qué destaca?
- Edita videos mediante comandos conversacionales con IA.

- Ofrece una línea de tiempo multipista profesional y totalmente editable.

- Integra Agent Skills y MCP para una edición avanzada y local.

- Soporta rendering con Remotion para resultados de alta calidad.

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para creadores de contenido que buscan automatizar la edición de video a través de interacciones de chat, manteniendo el control creativo total.
