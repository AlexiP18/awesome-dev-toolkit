# Libraries Dev

> Plataforma de librerías de efectos de UI y modelos ML on-device para React, SwiftUI y React Native, con bordes animados, indicadores de pensamiento y visualizadores de voz.

**👤 Publicado / Recomendado por:** Harshil Tomar ([@Hartdrawss](https://x.com/Hartdrawss))

## 💡 ¿Por qué destaca?
- Librerías de efectos visuales para React, SwiftUI y React Native

- Modelos ML on-device listos para usar

- Ejemplos como bordes animados, liquid metal y voice visualizers

## 📝 Notas Personales (Segundo Cerebro)
- Úsala para añadir efectos avanzados y modelos locales en apps multiplataforma sin montar infraestructura de ML desde cero.
