# Papermark

> Plataforma para compartir decks y documentos con analítica de apertura, páginas leídas y contenido omitido.

**👤 Publicado / Recomendado por:** Hasan Toor ([@hasantoxr](https://x.com/hasantoxr))

## 💡 ¿Por qué destaca?
- Seguimiento de quién abre el documento

- Métricas de páginas leídas y omitidas

- Compartición de presentaciones mediante enlaces

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para medir el interés real de inversores o clientes sobre una propuesta.
