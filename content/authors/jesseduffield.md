# Jesse Duffield (@jesseduffield)

> Jesse Duffield es un destacado desarrollador de software e innovador en herramientas de código abierto para la terminal. Es el creador de Lazygit, una popular y aclamada interfaz TUI para Git escrita en Go que transforma el flujo de control de versiones en consola, además de otros proyectos de gran impacto como Lazydocker. En sus redes comparte novedades sobre el desarrollo de utilidades de terminal, mejoras de ergonomía para desarrolladores y mejores prácticas en la creación de software CLI.
