# VirusTotal

> Plataforma de análisis de archivos, URLs y dominios que los escanea con decenas de motores antivirus y servicios de reputación en paralelo.

**👤 Publicado / Recomendado por:** Precis0x ([@precisox](https://x.com/precisox))

## 💡 ¿Por qué destaca?
- Escaneo con más de 70 motores antivirus y sandboxes de análisis dinámico

- API REST v3 para automatizar la comprobación de hashes, ficheros y URLs

- Búsqueda por hash para saber si un binario ya fue analizado previamente

- Gráficos de relaciones entre dominios, IPs y muestras de malware

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para verificar dependencias descargadas, binarios de terceros o enlaces sospechosos antes de ejecutarlos en CI o en tu máquina de desarrollo.
