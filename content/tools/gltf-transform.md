# glTF Transform

> Un SDK para JavaScript y TypeScript que permite la optimización, compresión y manipulación de assets 3D en formato glTF 2.0, tanto en el navegador como en Node.js, para mejorar el rendimiento.

**👤 Publicado / Recomendado por:** eigen ([@e1genqq](https://x.com/e1genqq))

## 💡 ¿Por qué destaca?
- SDK completo para el estándar glTF 2.0

- Optimización y compresión eficiente de assets 3D

- Manipulación programática de mallas y grafos de escena

- Funciona en entornos Web y Node.js para flujos de trabajo versátiles

## 📝 Notas Personales (Segundo Cerebro)
- Esencial para desarrolladores que trabajan con modelos 3D y necesitan optimizar su tamaño y rendimiento para aplicaciones web, móviles o experiencias de XR.
