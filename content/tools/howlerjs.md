# Howler.js

> Librería de audio para la web moderna que unifica Web Audio API y HTML5 Audio para reproducir sonidos, controlar volumen, fades, sprites y posiciones 3D.

**👤 Publicado / Recomendado por:** 露西的百宝箱 ([@Lucy_love_AI](https://x.com/Lucy_love_AI))

## 💡 ¿Por qué destaca?
- Fallback automático entre Web Audio API y HTML5 Audio

- Audio sprites para cargar un solo archivo y recortar efectos

- Control de fade, rate, loop, panning y posiciones espaciales

- Eventos de carga, reproducción y error por instancia

## 📝 Notas Personales (Segundo Cerebro)
- Úsala cuando tu app o experiencia 3D necesite efectos de sonido fiables en móvil/Safari, donde Web Audio puro requiere desbloqueo manual del contexto.
