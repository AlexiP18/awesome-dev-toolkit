# MiroFish

> Motor de inteligencia de enjambre escrito en Python que orquesta miles de agentes LLM para simular escenarios futuros a partir de noticias o textos de entrada. Permite explorar predicciones de opinión pública y mercados combinando grafos de conocimiento con simulación multiagente.

**👤 Publicado / Recomendado por:** 山羊赚钱笔记 ([@shanyanggm](https://x.com/shanyanggm))

## 💡 ¿Por qué destaca?
- Simulación de enjambre con miles de agentes LLM ejecutándose en paralelo sobre un mismo escenario

- Ingesta de noticias y textos reales como semilla para generar futuros plausibles y trayectorias alternativas

- Integración de grafos de conocimiento y memoria de agentes para mantener coherencia entre iteraciones

- Casos de uso preconfigurados para análisis de opinión pública y previsión financiera en Python 3

## 📝 Notas Personales (Segundo Cerebro)
- Útil para equipos que necesiten prototipar análisis de escenarios contrafactuales o estudios de opinión sin montar el pipeline desde cero; conviene revisar el consumo de tokens y la paralelización antes de lanzar simulaciones con miles de agentes en producción.
