# OmniRoute

> Pasarela de IA que expone un único endpoint para 231+ proveedores de modelos (50+ con tier gratuito), conectando Claude Code, Codex, Cursor y Cline a Claude, GPT y Gemini gratis.

**👤 Publicado / Recomendado por:** PA13L0 ([@Fluyeporlaweb](https://x.com/Fluyeporlaweb))

## 💡 ¿Por qué destaca?
- Un solo endpoint con 231+ proveedores de IA y 50+ con capa gratuita

- Comprime tokens entre 15% y 95% con auto-fallback si un proveedor falla

- Compatible con Claude Code, Codex, Cursor y Cline

- Soporta modelos como Claude, GPT, Gemini, GLM, DeepSeek y Kimi

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo como capa de enrutamiento para reducir costes de API y evitar caídas cuando un proveedor agota cuota, ideal en entornos de desarrollo con múltiples modelos.
