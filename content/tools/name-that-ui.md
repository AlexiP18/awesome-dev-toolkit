# Name That UI

> Diccionario visual de UI que asigna nombre, concepto, ejemplo y prompt listo para usar a cada elemento de una interfaz, pensado para que puedas describir con precisión a modelos de IA lo que quieres construir.

**👤 Publicado / Recomendado por:** Miguel Ángel Durán ([@midudev](https://x.com/midudev))

## 💡 ¿Por qué destaca?
- Catálogo visual de componentes y patrones de interfaz con su nomenclatura técnica correcta (cards, modals, toasts, breadcrumbs, etc.)

- Cada elemento incluye prompts pre-redactados listos para pegar en generadores de código con IA como v0, Cursor o Claude

- Referencias visuales de ejemplo para comparar variantes de un mismo componente antes de implementarlo

- Enfocado en la comunicación diseñador-desarrollador y en la precisión de los prompts de generación de UI

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo cuando estés maquetando con IA y no sepas cómo se llama exactamente un patrón de interfaz: busca el elemento, copia el prompt y adáptalo a tu stack (React, Tailwind, Vue) para obtener componentes mucho más fieles a lo que imaginas.
