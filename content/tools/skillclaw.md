# SkillClaw

> Herramienta en Python que organiza y mejora de forma colectiva tu librería de skills de agentes usando tus propias sesiones y un evolucionador agéntico.

**👤 Publicado / Recomendado por:** KATSU ([@katsudev](https://x.com/katsudev))

## 💡 ¿Por qué destaca?
- Evoluciona skills de agentes a partir de sesiones reales mediante un Agentic Evolver

- Aprendizaje continuo y auto-evolución de habilidades para LLMs

- Compatible con ecosistemas tipo OpenClaw y Hermes

- Más de 2.700 estrellas en GitHub

## 📝 Notas Personales (Segundo Cerebro)
- Úsala para mantener y refinar los prompts y skills de tus agentes de código; revisa qué sesiones alimentas para no filtrar datos sensibles.
