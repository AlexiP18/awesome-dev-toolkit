# Generative AI for Beginners

> Curso de 21 lecciones de Microsoft para construir aplicaciones de IA generativa, cubriendo LLMs, prompt engineering, RAG, fine-tuning y agentes.

> 🎓 **Promoción Académica:** Disponible para estudiantes o instituciones educativas.

**👤 Publicado / Recomendado por:** Dhairya Karekar ([@dkare1009](https://x.com/dkare1009))

## 💡 ¿Por qué destaca?
- 21 lecciones prácticas con código en Jupyter

- Cubre prompt engineering, RAG, fine-tuning y agentes

- Integración con Azure OpenAI y ChatGPT

- ~123k estrellas en GitHub

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para pasar de la teoría a construir tu primera app con LLMs; complementa cada lección con un proyecto propio.
