# Remotion

> Framework que permite crear vídeos de forma programática con React y TypeScript, componiendo cada escena como componentes y renderizándola a MP4 desde código o desde la nube.

**👤 Publicado / Recomendado por:** 露西的百宝箱 ([@Lucy_love_AI](https://x.com/Lucy_love_AI))

## 💡 ¿Por qué destaca?
- Composición de escenas con componentes y props de React, reutilizando lógica y estilos del proyecto web

- Remotion Studio para previsualizar el vídeo en el navegador con recarga en caliente

- Render por CLI o distribuido en la nube con Remotion Lambda para lotes grandes

- Salida a MP4/WebM con audio y datos dinámicos inyectados por props

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo cuando necesites generar cientos de vídeos personalizados (marketing, resúmenes, demos) a partir de datos y una plantilla React, en lugar de editar a mano en un editor tradicional.
