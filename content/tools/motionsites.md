# MotionSites

> Catálogo de prompts de IA y referencias de motion design listos para construir sitios web animados, pensado para desarrolladores frontend que buscan inspiración y código de partida rápido.

**👤 Publicado / Recomendado por:** Tran Mau Tri Tam ✪ ([@tranmautritam](https://x.com/tranmautritam))

## 💡 ¿Por qué destaca?
- Colección de prompts de IA orientados a generar sitios web con animaciones

- Galería de motion designs de referencia para copiar patrones visuales

- Permite pasar de la inspiración al prototipo usando asistentes de código con IA

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo cuando necesites arrancar una landing animada en horas: copia el prompt, adáptalo a tu stack (React/Tailwind) y refina la animación a mano.
