# soundcn

> Colección open source de más de 700 efectos de sonido curados para interfaces web modernas, integrable con Shadcn UI y React.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Más de 700 efectos de sonido de UI listos para usar

- Instalación con un solo comando y compatible con Shadcn UI

- Código abierto en TypeScript para personalizar y previsualizar sonidos

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para añadir feedback sonoro sutil a botones, notificaciones y modales en aplicaciones React sin diseñar audio desde cero.
