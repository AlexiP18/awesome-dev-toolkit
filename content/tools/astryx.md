# Astryx

> Sistema de diseño open source de Meta (licencia MIT) escrito en TypeScript, con más de 150 componentes listos para usar y pensado para que tanto desarrolladores como agentes de IA construyan interfaces consistentes sobre las mismas piezas.

**👤 Publicado / Recomendado por:** marcus ([@marcusyul](https://x.com/marcusyul))

## 💡 ¿Por qué destaca?
- Más de 150 componentes preconstruidos listos para producción, usados internamente en más de 13.000 apps de Meta durante 8 años

- Theming avanzado: se cambia el tema visual sin tocar el código de los componentes

- Enfoque 'agent ready': los agentes de IA pueden generar UI reutilizando exactamente los mismos bloques del sistema

- Cero build plugins ni configuración extraña; se integra directamente en el stack frontend (React/TypeScript)

- Licencia MIT con ~14k estrellas en GitHub, lo que permite uso comercial y modificación libre

## 📝 Notas Personales (Segundo Cerebro)
- Adóptalo si buscas un design system maduro y battle-tested para acelerar el desarrollo de interfaces en React/TypeScript, especialmente si trabajas con generación asistida por IA; revisa la documentación del repo para el setup del theming y la lista completa de componentes antes de migrar tu propia librería de UI.
