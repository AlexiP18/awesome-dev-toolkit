# LibreChat

> Interfaz web open source tipo ChatGPT que unifica ChatGPT, Claude, Gemini y otros modelos en un solo chat autohospedado con agentes y MCP.

**👤 Publicado / Recomendado por:** brenz. ([@brenzhills](https://x.com/brenzhills))

## 💡 ¿Por qué destaca?
- Permite cambiar entre proveedores como OpenAI, Anthropic, Gemini, Groq, Mistral y OpenRouter

- Incluye agentes, MCP, búsqueda de mensajes, Code Interpreter y autenticación multiusuario

- Desarrollado en TypeScript y pensado para self-hosting

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para equipos que quieren una alternativa privada a ChatGPT con control de modelos y despliegue propio.
