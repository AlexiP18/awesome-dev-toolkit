# librani Motion Library

> Biblioteca de recursos gratuitos para crear contenido visual y motion, con prompts listos para copiar, skills instalables y un film inicial descargable.

**👤 Publicado / Recomendado por:** Raniii ([@ranimth07](https://x.com/ranimth07))

## 💡 ¿Por qué destaca?
- Prompts de copiar y pegar para generar estilos visuales y motion

- Skills ya preparados para instalar y reutilizar en el flujo de trabajo

- Starter film descargable para explorar y producir contenido desde cero

- Estilos de motion films orientados a marcas crypto, escritos como código
