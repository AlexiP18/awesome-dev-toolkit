# Superpowers

> Framework de skills agénticas y metodología de desarrollo self-hosted para agentes de IA, con más de 300.000 estrellas en GitHub y flujos de trabajo subagent-driven.

**👤 Publicado / Recomendado por:** PA13L0 ([@Fluyeporlaweb](https://x.com/Fluyeporlaweb))

## 💡 ¿Por qué destaca?
- Framework de skills agénticas y metodología de desarrollo

- Enfoque self-hosted sin depender de SaaS de pago

- Impulsa flujos de 'subagent-driven development'

- Más de 300k estrellas, entre los repos más populares de GitHub

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para estructurar el trabajo de agentes de IA en tus proyectos con una metodología reproducible, sustituyendo herramientas de pago tipo Notion o Linear en la gestión de tareas.
