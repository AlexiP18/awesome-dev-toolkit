# Raindrop.io

> Gestor de marcadores multiplataforma que organiza enlaces, colecciones y capturas con búsqueda de texto completo.

**👤 Publicado / Recomendado por:** Alejo ([@ecommartinez](https://x.com/ecommartinez))

## 💡 ¿Por qué destaca?
- Colecciones anidables con etiquetas y filtros

- Extensiones para todos los navegadores y apps móviles

- API REST y sincronización en la nube

## 📝 Notas Personales (Segundo Cerebro)
- Perfecto para mantener una base curada de documentación, repos y artículos técnicos sincronizada entre equipos y dispositivos.
