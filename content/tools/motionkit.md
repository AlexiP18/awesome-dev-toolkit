# MotionKit

> Librería de 133 componentes React animados con TypeScript, Tailwind CSS y Motion, listos para copiar y poseer.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- 133 componentes animados: botones, efectos de texto, fondos y secciones completas

- Construidos con TypeScript, Tailwind CSS y Motion

- Copias el código y lo posees, sin dependencias de paquetes externos

## 📝 Notas Personales (Segundo Cerebro)
- Perfecto para añadir microinteracciones y secciones animadas a proyectos React con Tailwind de forma rápida y personalizable.
