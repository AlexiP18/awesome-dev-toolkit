# prompts.chat (Awesome ChatGPT Prompts)

> Biblioteca open source y autoalojable con miles de prompts listos para copiar y pegar, compatibles con Claude, ChatGPT, Gemini, Llama y cualquier modelo, organizada por categorías y con sistema de colecciones, votos y mejoras comunitarias.

**👤 Publicado / Recomendado por:** Jokker ([@0xJokker](https://x.com/0xJokker))

## 💡 ¿Por qué destaca?
- Catálogo masivo de prompts indexados por categoría, caso de uso y modelo compatible (Claude, ChatGPT, Gemini, Llama, etc.)

- Sistema de colecciones personales y bibliotecas privadas para guardar, versionar y reutilizar prompts como activos de equipo

- Flujo comunitario tipo repositorio de código: proponer mejoras, votar los mejores prompts y compartirlos públicamente

- Distribución open source con opción de self-hosting para organizaciones con privacidad total de sus datos y prompts internos

## 📝 Notas Personales (Segundo Cerebro)
- Despliégalo con Docker en tu propia infraestructura si manejas prompts con datos sensibles de cliente; para uso individual, clona el repo y mantén tus colecciones versionadas en Git junto al código del proyecto para reutilizarlas entre equipos y modelos.
