# Agentor

> Framework open source para construir y desplegar agentes de IA con soporte A2A, descubrimiento de agentes, streaming y compartición de artefactos.

**👤 Publicado / Recomendado por:** Leonard Rodman ([@RodmanAi](https://x.com/RodmanAi))

## 💡 ¿Por qué destaca?
- Añade comunicación agent-to-agent (A2A) y descubrimiento dinámico entre agentes

- Soporta streaming de respuestas y compartición de artefactos entre agentes

- Incluye herramientas MCP y utilidades para construir asistentes de IA desplegables

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para orquestar sistemas multiagente donde varios agentes deban descubrirse y colaborar en tiempo real, por ejemplo asistentes empresariales o flujos MCP.
