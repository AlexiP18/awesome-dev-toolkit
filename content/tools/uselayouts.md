# UseLayouts

> Librería open source y gratuita de componentes React animados con Motion (Framer Motion) y Tailwind CSS, instalable vía shadcn CLI o copiando el código.

**👤 Publicado / Recomendado por:** Harshil Tomar ([@Hartdrawss](https://x.com/Hartdrawss))

## 💡 ¿Por qué destaca?
- Componentes React animados con Framer Motion y Tailwind CSS

- Instalación mediante shadcn CLI o copia directa del código

- Licencia MIT y uso gratuito

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para añadir microinteracciones y secciones animadas a proyectos Next.js/React con shadcn/ui sin dependencias cerradas.
