# Workout Guide

> Paquete npm framework-neutral con un catálogo abierto de 302 ejercicios y 906 ilustraciones SVG vectoriales pulidas, con metadata indexable para búsquedas por músculo o equipamiento, pensado para integrarse en apps web y mobile de fitness, entrenamiento o educación.

**👤 Publicado / Recomendado por:** Brais Moure ([@MoureDev](https://x.com/MoureDev))

## 💡 ¿Por qué destaca?
- 302 ejercicios documentados con 906 frames SVG vectoriales de alta calidad, escalables y ligeros

- Metadata buscable que permite filtrar ejercicios por grupo muscular o equipamiento requerido

- Paquete npm neutral respecto al framework, integrable en React, Vue, Svelte o vanilla JS y en apps móviles

- Guías de integración simples y licencia abierta para usar en proyectos comerciales o educativos

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para acelerar el desarrollo de apps de fitness, rutinas de gimnasio o plataformas de entrenamiento personal: instala el paquete npm y consume el JSON de metadata para construir buscadores y filtros sin necesidad de generar ilustraciones propias.
