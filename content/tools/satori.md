# Satori

> Librería de Vercel que convierte HTML y CSS (o JSX) en SVG de forma instantánea, pensada para generar imágenes Open Graph y tarjetas de título en el servidor.

**👤 Publicado / Recomendado por:** 露西的百宝箱 ([@Lucy_love_AI](https://x.com/Lucy_love_AI))

## 💡 ¿Por qué destaca?
- Render de JSX/HTML+CSS a SVG sin navegador headless

- Subconjunto de CSS con flexbox y fuentes personalizadas embebidas

- Base de `@vercel/og` para generar OG images en edge functions

- Salida SVG convertible a PNG con resvg

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para generar tarjetas de título por artículo o escena de vídeo (combinado con Remotion), donde necesitas imágenes deterministas sin coste de un navegador.
