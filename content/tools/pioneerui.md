# PioneerUI

> Biblioteca de componentes moderna y consciente del tema para Next.js y React Server Components, enfocada en construir aplicaciones web accesibles y de alto rendimiento.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Más de 50 componentes animados listos para React y Next.js

- Soporte nativo de React Server Components y theming dinámico

- Diseñada para accesibilidad y rendimiento en producción

- Compatible con el ecosistema moderno de Next.js App Router

## 📝 Notas Personales (Segundo Cerebro)
- Adóptala en proyectos Next.js que necesiten componentes animados accesibles sin montar un design system desde cero, especialmente al usar RSC.
