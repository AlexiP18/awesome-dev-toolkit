# FrontAgent

> Plataforma open source de agente de IA para frontend con CLI, extensión de VS Code, servidor MCP, planificación RAG y automatización de navegador.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Incluye CLI, extensión de VS Code y aplicación de escritorio

- Servidor MCP, planificación RAG, Skills y guardrails SDD

- Automatización de navegador y modelos de planificación LoRA

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para acelerar tareas de desarrollo frontend asistido por IA, como generación de componentes, refactors guiados y pruebas automatizadas en el navegador.
