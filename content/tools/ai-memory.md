# ai-memory

> Solución de código abierto para la memoria a largo plazo en CLIs de agentes de codificación, facilitando la transferencia de contexto entre diferentes proveedores de agentes de IA.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Ofrece memoria a largo plazo para agentes de codificación.

- Facilita la transferencia de datos y contexto entre diferentes proveedores de agentes.

- Desarrollado en Rust y de código abierto.

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para proyectos que requieren persistencia de memoria y coordinación de tareas complejas entre múltiples agentes de IA en entornos CLI.
