# Lexend

> Familia tipográfica de Google Fonts diseñada para reducir el estrés visual y mejorar la velocidad y comprensión lectora, originalmente pensada para personas con dislexia. Ideal para interfaces con foco en accesibilidad.

**👤 Publicado / Recomendado por:** 𝐍𝐨𝐚𝐡 ([@noahelhadedy](https://x.com/noahelhadedy))

## 💡 ¿Por qué destaca?
- Diseñada con base en investigación sobre rendimiento lector

- Amplia gama de pesos y anchos como variable font

- Disponible gratis vía Google Fonts API y @fontsource

- Optimizada para textos largos y entornos de lectura digital

## 📝 Notas Personales (Segundo Cerebro)
- Empléala en productos educativos, lectores, documentación o cualquier UI donde la legibilidad sea crítica; combínala con tamaños base ≥16px y buen contraste para maximizar el beneficio.
