# holo-card-studio

> Skill para Codex que convierte una descripción o imagen de referencia en una carta coleccionable 3D: genera 4 capas de arte (sujeto, fondo, lineart y texto), un archivo .blend editable y una página interactiva en Three.js con paralaje, efecto foil y estrellas que reacciona al mouse.

**👤 Publicado / Recomendado por:** Erick ([@ErickSky](https://x.com/ErickSky))

## 💡 ¿Por qué destaca?
- Genera automáticamente 4 capas de arte separadas (sujeto, fondo, lineart y texto) listas para composición y animación por capas

- Exporta un archivo .blend editable en Blender, no solo un render plano, para ajustar materiales, iluminación y geometría

- Produce una página web con Three.js donde la carta se gira, se voltea y brilla con el cursor, con shaders de foil y paralaje

- Preserva el sujeto, estilo, tipografía y formato solicitados a partir de un prompt o una imagen de referencia subida

- Implementado en Python como skill de Codex: contiene solo código y texto, el arte generado se guarda en el proyecto de salida del usuario

## 📝 Notas Personales (Segundo Cerebro)
- Ideal si quieres lanzar rápido una tienda o catálogo de cartas coleccionables 3D: personaliza nombre, paleta de colores y franja (stripe), ejecuta el skill y despliega el resultado estático de Three.js en Vercel o GitHub Pages; revisa los materiales del .blend si necesitas un render de alta calidad para marketing.
