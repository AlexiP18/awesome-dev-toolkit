# ECC

> Sistema de optimización del rendimiento de agentes que empaqueta skills, instintos, memoria y seguridad en un solo pack para Claude Code, Codex, Cursor y OpenCode.

**👤 Publicado / Recomendado por:** niko. ([@nikosolenne](https://x.com/nikosolenne))

## 💡 ¿Por qué destaca?
- Pack unificado de skills, memoria persistente y capa de seguridad para agentes

- Compatible con Claude Code, Codex, Cursor y OpenCode

- Enfoque research-first: el agente investiga antes de escribir código

- Implementado en JavaScript con soporte de MCP e integración en herramientas dev

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo si quieres endurecer y estandarizar de una vez tu entorno de agentes; revisa la configuración de seguridad para que no bloquee comandos legítimos de tu stack.
