# Cap

> Alternativa open source a Loom para grabar pantalla, crear demos de producto y compartir videos con enlaces.

**👤 Publicado / Recomendado por:** 0xMarioNawfal ([@RoundtableSpace](https://x.com/RoundtableSpace))

## 💡 ¿Por qué destaca?
- Permite grabar pantalla y crear videos de demos o tutoriales

- Está construido con Rust, Tauri y tecnologías web

- Ofrece una experiencia multiplataforma orientada a compartir grabaciones

- Es una alternativa open source a herramientas comerciales de screen recording

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para grabar demos de producto, reportar bugs con video o crear material de onboarding sin depender de Loom.
