# Backgrounds Supply

> Proveedor de fondos y texturas gráficas listas para usar en secciones hero, tarjetas y presentaciones, evitando depender de imágenes genéricas de stock.

**👤 Publicado / Recomendado por:** Bardhyl Bytyqi ([@BardhylBytyqi](https://x.com/BardhylBytyqi))

## 💡 ¿Por qué destaca?
- Fondos en distintos formatos y resoluciones

- Texturas, degradados y patrones abstractos para web

- Recursos descargables integrables como CSS o imagen

## 📝 Notas Personales (Segundo Cerebro)
- Comprime y sirve los fondos en WebP o AVIF para no penalizar el LCP de tu landing.
