# Arc UI

> Librería de componentes y bloques React animados para shadcn y Next.js, con integración vía shadcn CLI y servidor MCP para que agentes de IA construyan interfaces.

**👤 Publicado / Recomendado por:** Harshil Tomar ([@Hartdrawss](https://x.com/Hartdrawss))

## 💡 ¿Por qué destaca?
- Componentes y bloques animados para shadcn y Next.js

- Se añade con shadcn CLI

- Incluye servidor MCP para que agentes de IA generen UI
