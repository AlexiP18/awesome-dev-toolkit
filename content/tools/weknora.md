# WeKnora

> Plataforma open source de conocimiento con LLM que convierte documentos en un sistema RAG consultable, un agente autónomo y una wiki autoactualizable.

**👤 Publicado / Recomendado por:** Shruti Codes ([@Shruti_0810](https://x.com/Shruti_0810))

## 💡 ¿Por qué destaca?
- Pipeline RAG con embeddings, reranking y búsqueda semántica/vectorial

- Agente de razonamiento autónomo y wiki mantenida automáticamente

- Soporte multi-tenant y conectores para Ollama/OpenAI

- Implementado en Go para despliegues escalables

## 📝 Notas Personales (Segundo Cerebro)
- Úsala para construir asistentes de conocimiento corporativo sobre documentación interna con trazabilidad y búsqueda semántica.
