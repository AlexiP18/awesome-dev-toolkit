# API Finder

> Directorio navegable de APIs públicas organizadas por categoría que detalla autenticación, soporte CORS y modelo de precios de cada endpoint.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Catálogo de APIs públicas agrupadas por categoría funcional

- Fichas con información sobre autenticación, CORS y pricing de cada API

- Buscador para localizar rápidamente una API según el caso de uso

## 📝 Notas Personales (Segundo Cerebro)
- Consúltalo al inicio de un proyecto para encontrar servicios externos listos para integrar sin tener que construir esa funcionalidad desde cero, verificando antes las limitaciones de CORS y cuotas gratuitas.
