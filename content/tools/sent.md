# Sent

> API de envío de SMS a precio muy bajo pensada para integrar notificaciones, verificación de teléfono y alertas transaccionales desde el backend de cualquier aplicación.

**👤 Publicado / Recomendado por:** Bardhyl Bytyqi ([@BardhylBytyqi](https://x.com/BardhylBytyqi))

## 💡 ¿Por qué destaca?
- API HTTP sencilla para enviar SMS transaccionales

- Coste por mensaje muy reducido frente a proveedores tradicionales

- Integrable en flujos de autenticación OTP y alertas de sistema

## 📝 Notas Personales (Segundo Cerebro)
- Añade rate limiting y verificación de formato E.164 en tu backend antes de llamar a la API para evitar gastos por mensajes fallidos.
