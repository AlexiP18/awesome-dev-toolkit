# Aceternity UI

> Biblioteca de componentes React y Tailwind CSS con más de 200 bloques copiables, plantillas de landing y animaciones con Motion para acelerar interfaces de alto impacto visual.

**👤 Publicado / Recomendado por:** 𝐍𝐨𝐚𝐡 ([@noahelhadedy](https://x.com/noahelhadedy))

## 💡 ¿Por qué destaca?
- 200+ componentes copy-paste en React + Tailwind CSS + Motion

- Bloques completos y plantillas de landing listas para producción

- Efectos avanzados: spotlight, beams, glowing cards, parallax y gradientes animados

## 📝 Notas Personales (Segundo Cerebro)
- Ideal cuando necesitas efectos visuales vistosos sin escribirlos desde cero: copia el componente, revisa sus dependencias (framer-motion) y adapta los tokens de color a tu design system.
