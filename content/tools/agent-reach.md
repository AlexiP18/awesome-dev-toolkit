# Agent-Reach

> CLI open source que da a tu agente de IA capacidad de lectura y búsqueda en X, Reddit, YouTube, GitHub, Bilibili y XiaoHongShu sin pagar APIs.

**👤 Publicado / Recomendado por:** KATSU ([@katsudev](https://x.com/katsudev))

## 💡 ¿Por qué destaca?
- Un único CLI y servidor MCP para consultar múltiples redes sociales

- Scrapers integrados de Twitter/X, Reddit, YouTube, GitHub, Bilibili y XiaoHongShu

- Cero costes de API y compatibilidad con Claude Code y Cursor

- Escrito en Python y orientado a infraestructura de agentes

## 📝 Notas Personales (Segundo Cerebro)
- Conéctalo como servidor MCP a tu agente para investigación de mercado, monitorización de menciones o generación de contenido con contexto real de redes.
