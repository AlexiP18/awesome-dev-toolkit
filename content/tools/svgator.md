# SVGator

> Editor online gratuito para crear animaciones SVG personalizadas sin escribir código y exportarlas fácilmente a sitios web o aplicaciones.

**👤 Publicado / Recomendado por:** Dev Patel ([@DevDsgn](https://x.com/DevDsgn))

## 💡 ¿Por qué destaca?
- Editor visual de animaciones SVG en el navegador

- Exportación de animaciones listas para web y apps

- Soporte para animar paths, formas y transformaciones

- Plan gratuito para empezar sin instalar software

## 📝 Notas Personales (Segundo Cerebro)
- Adecuada cuando los iconos animados existentes no encajan y se necesita animar un SVG propio con control preciso de keyframes y tiempos.
