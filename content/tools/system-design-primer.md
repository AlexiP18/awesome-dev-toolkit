# system-design-primer

> Guía de referencia para aprender diseño de sistemas a gran escala, con diagramas, discusiones de trade-offs y preparación para entrevistas de arquitectura.

**👤 Publicado / Recomendado por:** Shruti Codes ([@Shruti_0810](https://x.com/Shruti_0810))

## 💡 ¿Por qué destaca?
- Explicaciones de escalabilidad, caché, balanceo de carga y consistencia

- Casos de estudio de sistemas reales y ejercicios de diseño

- Soluciones con código en Python y mazos de flashcards Anki

## 📝 Notas Personales (Segundo Cerebro)
- Estúdiala antes de entrevistas de arquitectura de sistemas distribuidos y para justificar decisiones de diseño.
