# Scroll Shaders

> Biblioteca de 117 shaders WebGL en 11 estilos que proporcionan fondos animados de alta calidad para secciones hero de sitios web, disponibles como código o video.

**👤 Publicado / Recomendado por:** Aman Singh ([@amananimates](https://x.com/amananimates))

## 💡 ¿Por qué destaca?
- 117 shaders WebGL para fondos animados.

- Disponibles en 11 estilos diversos (mesh, grain, dither, liquid metal, glass).

- Se pueden copiar como código (React o HTML), descargar como video o imagen estática.

- Optimizados para rendimiento, pausando automáticamente fuera de pantalla para mantener la velocidad de la página.

## 📝 Notas Personales (Segundo Cerebro)
- Implementa estos shaders para darle un aspecto sofisticado a tus secciones hero sin sacrificar la velocidad de carga de tu página web.
