# ShapeFactory

> Conjunto de herramientas de diseño creadas por diseñadores para generar logos, paletas de color y degradados listos para usar en proyectos web y de producto.

**👤 Publicado / Recomendado por:** Tran Mau Tri Tam ✪ ([@tranmautritam](https://x.com/tranmautritam))

## 💡 ¿Por qué destaca?
- Generador de logos con parámetros ajustables y exportación

- Creador de paletas de color y combinaciones de gradientes CSS

- Suite de utilidades de diseño sin curva de aprendizaje

## 📝 Notas Personales (Segundo Cerebro)
- Úsala para definir la identidad visual de side projects o MVPs; exporta los gradientes como CSS y consolida los colores en variables de tu tema.
