# Wayback Machine (Internet Archive)

> Archivo histórico de la web que permite recuperar versiones antiguas o borradas de cualquier página y consultar su evolución a lo largo del tiempo.

**👤 Publicado / Recomendado por:** Precis0x ([@precisox](https://x.com/precisox))

## 💡 ¿Por qué destaca?
- Capturas históricas de miles de millones de URLs desde 1996

- API de disponibilidad y CDX para consultar snapshots por fecha programáticamente

- Recuperación de documentación técnica y páginas de productos descontinuados

- Acceso a colecciones de textos, software y medios del Internet Archive
