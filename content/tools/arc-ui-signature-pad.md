# Arc UI Signature Pad

> Componente de firma digital para React que dibuja trazos de tinta suaves con grosor variable según la velocidad del puntero, permitiendo guardar la firma como PNG o SVG.

**👤 Publicado / Recomendado por:** Elia ([@eliakuratli](https://x.com/eliakuratli))

## 💡 ¿Por qué destaca?
- Tinta suave que se adelgaza con la velocidad del trazo (simulación de presión)

- Funciones de deshacer y reproducir (replay) la firma dibujada

- Exportación a PNG o SVG lista para almacenar

- Instalación vía shadcn CLI o mediante herramientas de IA desde la documentación

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para formularios de aceptación de términos, contratos digitales o check-in de usuarios donde se requiera capturar una firma manuscrita sin salir de React y con exportación vectorial cuando se necesita calidad de impresión.
