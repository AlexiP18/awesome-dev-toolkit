# devl

> Biblioteca gratuita y open source de componentes, bloques y pantallas React para shadcn, con 277 recursos de UI, motion e ilustraciones sobre Base UI y Tailwind.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- 277 componentes, bloques y pantallas React gratuitos

- Compatible con shadcn y construido sobre Base UI y Tailwind

- Incluye motion e ilustraciones

- Permite copiar el código o instalar con la CLI de shadcn

## 📝 Notas Personales (Segundo Cerebro)
- Úsala para acelerar la creación de interfaces React profesionales con shadcn, copiando componentes o instalándolos directamente en el proyecto.
