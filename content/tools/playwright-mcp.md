# Playwright MCP

> Servidor MCP de Microsoft que deja a un LLM usar el navegador mediante snapshots de accesibilidad estructurados.

**👤 Publicado / Recomendado por:** divyansh tiwari ([@DivyanshT91162](https://x.com/DivyanshT91162))

## 💡 ¿Por qué destaca?
- Sin capturas ni modelos de visión

- Snapshots de accesibilidad estructurados

## 📝 Notas Personales (Segundo Cerebro)
- Most AI agents stop working the moment they need to extract clean data from a real website.

10 open-source GitHub repositories for web scraping, browser agents, and feeding live web data into AI workflows:

1. Scrapy
Classic Python crawling framework. Choose this when you need to crawl thousands of pages on a schedule.

https://t.co/dYU5UOfxJ9

2. Crawl4AI
Converts any website into clean, LLM-ready Markdown. Filters menus and footers, supports MCP, Apache 2.0.

https://t.co/NiBk4Rak8O

3. Playwright MCP
Microsoft's MCP server that allows LLM to run in-browser via structured accessibility snapshots, so you don't need screenshots or visual models. https://t.co/vbeNT60Cw5

4. Oxylabs Web API MCP
Connects Cloud Code, Codex, or Cloud Desktop to the Oxylabs Web API so your agent can pull live web data from within a chat. Use a hosted server or host it yourself. Requires an Oxylabs Web API key.

https://t.co/OIlRFypLDe

5. Browser Use
A Python library that allows the AI agent to run a browser to complete tasks. Bring your own LLM. MIT licensed.

https://t.co/kqvG8Svs9b

6. Stagehand
An SDK for the browser agent that includes three primitives: Act, Extract, and Observe. You write steps in plain English, and Extract returns schema-validated data. https://t.co/6Tq8Bc9ppR

7. ScrapeGraphAI
Specify what you want in a prompt and create an LLM scraping pipeline. Works with local models via Ollama.

https://t.co/mUoHg20frD

8. Trafilatura
Extracts main text, metadata, and comments from raw HTML. Outputs Markdown, JSON, CSV, or XML. Good for cleaning pages before RAG.

https://t.co/lzMUYlqA1M

9. MarkItDown
Microsoft's tool for converting PDF, Word, Excel, PowerPoint, HTML, and more to Markdown for LLMs.

https://t.co/5Yvio0YkxI

10. MCP Python SDK
Official SDK for building your own MCP servers and clients. When none of the above fit, wrap your own scraper as a tool.
https://t.co/PwThw5KmX9
