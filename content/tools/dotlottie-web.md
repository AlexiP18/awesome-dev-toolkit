# dotLottie Web

> Reproductor web de alto rendimiento para Lottie y dotLottie basado en Rust y WASM, con soporte de React, Vue, Svelte, Solid y Web Components.

**👤 Publicado / Recomendado por:** 露西的百宝箱 ([@Lucy_love_AI](https://x.com/Lucy_love_AI))

## 💡 ¿Por qué destaca?
- Render con ThorVG/WASM, más rápido y ligero que lottie-web en canvas/WebGL

- Soporte del formato .lottie empaquetado (assets, temas y state machines)

- Componentes nativos para React, Vue, Svelte, Solid.js y Web Components

- Control de reproducción, segmentos, velocidad y temas en tiempo de ejecución

## 📝 Notas Personales (Segundo Cerebro)
- Migra de lottie-web a dotlottie-web si tus animaciones Lottie pesan demasiado o necesitas control de temas y mejor rendimiento en móvil.
