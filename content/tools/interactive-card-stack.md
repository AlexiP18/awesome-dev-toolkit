# Interactive Card Stack

> Componente React animado que renderiza una pila dispersa de tarjetas tipo foto, permitiendo enfocar cada tarjeta mediante arrastre, clic o teclas de flecha. Se instala directamente con la CLI de shadcn y es gratuito y de código abierto.

**👤 Publicado / Recomendado por:** Alex Tatu ([@uiNerd](https://x.com/uiNerd))

## 💡 ¿Por qué destaca?
- Instalación vía shadcn CLI, integrándose con proyectos React + Tailwind existentes

- Interacciones múltiples: drag & drop, clic y navegación con teclas de flecha para enfocar tarjetas

- Animaciones fluidas de apilamiento y dispersión de tarjetas con efecto de profundidad

- Código abierto y gratuito, personalizable y adaptable a distintos design systems

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para portfolios, galerías de imágenes, testimonios o secciones de producto donde quieras destacar contenido visual con una interacción llamativa; cópialo y adáptalo con tus propias tarjetas y transiciones para diferenciarte de los layouts convencionales.
