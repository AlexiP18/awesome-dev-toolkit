# archive.today

> Servicio de preservación que guarda capturas permanentes de páginas web con sus recursos, incluso de contenido dinámico.

**👤 Publicado / Recomendado por:** Alejo ([@ecommartinez](https://x.com/ecommartinez))

## 💡 ¿Por qué destaca?
- Captura de HTML, CSS e imágenes en un snapshot

- Búsqueda por URL, dominio o texto

- Añade nuevas capturas al instante

## 📝 Notas Personales (Segundo Cerebro)
- Enlaza siempre una copia de archive.ph en documentación técnica para evitar que la referencia se rompa si la web original desaparece.
