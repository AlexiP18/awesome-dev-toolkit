> Un framework de Python mantenido por la comunidad para crear animaciones matemáticas, diagramas y explainers visualmente atractivos y precisos.

## 💡 ¿Por qué destaca?
- Framework Python para animaciones matemáticas

- Creación de diagramas y explicaciones animadas

- Ideal para contenido educativo y científico
