# Colorion Text Effects

> Galería de 123 efectos y animaciones de texto en CSS puro (glitch, neón, degradado, máquina de escribir, 3D) que puedes copiar y pegar sin añadir JavaScript a tu proyecto.

**👤 Publicado / Recomendado por:** Tran Mau Tri Tam ✪ ([@tranmautritam](https://x.com/tranmautritam))

## 💡 ¿Por qué destaca?
- Más de 120 efectos de texto con código CSS copiable al instante

- Sin dependencias de JavaScript, ideal para rendimiento y SEO

- Incluye estilos glitch, neón, gradientes animados, typewriter y 3D

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para titulares de hero sections o branding rápido; agrupa los keyframes en tu hoja global y limita las animaciones simultáneas para no penalizar el rendimiento móvil.
