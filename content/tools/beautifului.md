# BeautifulUI

> Pequeña librería de primitivas de UI muy cuidadas y copy-paste para interfaces nativas de IA, como chats de agentes, estados de pensamiento y aprobaciones human-in-the-loop.

**👤 Publicado / Recomendado por:** Harshil Tomar ([@Hartdrawss](https://x.com/Hartdrawss))

## 💡 ¿Por qué destaca?
- Componentes copy-paste para interfaces de agentes de IA

- Incluye chat, thinking states y aprobaciones human-in-the-loop

- Diseño extremadamente cuidado para interacción humano-agente

## 📝 Notas Personales (Segundo Cerebro)
- Úsala cuando construyas asistentes o agentes conversacionales y necesites componentes de chat y estados de IA listos para producción.
