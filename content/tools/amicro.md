# Amicro

> Librería open-source de más de 170 componentes React listos para copiar y pegar, especializada en micro-interacciones y transiciones de movimiento: botones animados, tarjetas 3D, loaders, efectos de texto y gráficos, construida sobre Motion (Framer Motion) y Tailwind CSS.

**👤 Publicado / Recomendado por:** Abraham John ([@Abmankendrick](https://x.com/Abmankendrick))

## 💡 ¿Por qué destaca?
- Más de 170 componentes de micro-interacción y motion listos para copiar y pegar directamente en el proyecto, sin dependencias de registro ni pasarelas de pago

- Construida con Motion (Framer Motion) y Tailwind CSS, por lo que se integra de forma nativa en stacks React con utilidades de estilos atómicas

- Instalación centralizada mediante un único comando CLI que añade todos los componentes a la base de código del usuario

- Incluye animaciones de botones, tarjetas 3D, loaders, efectos tipográficos animados y gráficos para dashboards y web apps

- Repositorio en TypeScript con licencia open-source y comunidad activa (más de 2.7k estrellas en GitHub)

## 📝 Notas Personales (Segundo Cerebro)
- Ideal cuando necesitas elevar la percepción de calidad de una web app o dashboard React con detalles de motion pulidos sin diseñar las animaciones desde cero. Revisa el código de cada componente antes de copiarlo para adaptar duraciones y easings a tu design system y verificar que las animaciones respeten la preferencia prefers-reduced-motion.
