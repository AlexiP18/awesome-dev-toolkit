# JSON Formatter

> Herramienta web que formatea, valida y minifica JSON, mostrando la ruta de error exacta cuando la sintaxis falla.

**👤 Publicado / Recomendado por:** Alejo ([@ecommartinez](https://x.com/ecommartinez))

## 💡 ¿Por qué destaca?
- Validación con indicación de línea y columna

- Conversión JSON a XML, CSV o YAML

- Comparador de dos documentos JSON

## 📝 Notas Personales (Segundo Cerebro)
- Cuando una API devuelve un JSON malformado, pégalo aquí para localizar el carácter que rompe el parseo.
