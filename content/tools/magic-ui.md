# Magic UI

> Conjunto de componentes y plantillas de UI animadas para React y Tailwind CSS, pensado para dar un acabado pulido a landings y páginas de marketing sin partir de cero.

**👤 Publicado / Recomendado por:** 𝐍𝐨𝐚𝐡 ([@noahelhadedy](https://x.com/noahelhadedy))

## 💡 ¿Por qué destaca?
- Componentes React + Tailwind CSS con animaciones preconfiguradas

- Instalación por CLI compatible con proyectos basados en shadcn/ui

- Bloques de marketing: marquee, bento grid, terminal, shimmer button

## 📝 Notas Personales (Segundo Cerebro)
- Combínalo con shadcn/ui para mantener consistencia: instala solo los bloques necesarios vía CLI y verifica el coste de animación en Lighthouse antes de desplegar.
