# React Three Fiber

> Renderer declarativo de Three.js para React que permite construir escenas 3D como árbol de componentes con estado, hooks y props reactivos.

**👤 Publicado / Recomendado por:** 露西的百宝箱 ([@Lucy_love_AI](https://x.com/Lucy_love_AI))

## 💡 ¿Por qué destaca?
- Escenas 3D declarativas en JSX con reconciliación por componentes

- Hook `useFrame` para animación por frame y actualización de estado sin re-render

- Integración con Suspense para carga asíncrona de modelos y texturas

- Ecosistema pmndrs (drei, rapier, postprocessing) como piezas intercambiables

## 📝 Notas Personales (Segundo Cerebro)
- Elígelo siempre que el proyecto ya sea React: evita el boilerplate imperativo de Three.js y facilita separar escena, lógica y UI.
