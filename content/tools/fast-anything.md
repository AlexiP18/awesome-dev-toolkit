# fast-anything

> Herramienta para perfilar apps Python, Node o Ruby y portar solo las funciones lentas con tu agente de código, verificando que se comporten igual.

**👤 Publicado / Recomendado por:** Ram Maheshwari ([@rammcodes](https://x.com/rammcodes))

## 💡 ¿Por qué destaca?
- Enfoque: reescribir el 5% lento en vez de todo en Rust

- Profiling para localizar hot paths

- Pruebas de equivalencia del comportamiento tras el port
