# Sure

> App open source de finanzas personales (sucesora comunitaria de Maybe Finance) para gestionar activos, deudas y flujo de caja, autoalojable con Docker.

**👤 Publicado / Recomendado por:** 旺旺 ([@TiagerBao](https://x.com/TiagerBao))

## 💡 ¿Por qué destaca?
- Patrimonio neto, ingresos y gastos en un solo lugar

- Asistente de IA para analizar tus finanzas

- Self-hosting con Docker y API para agentes

- Acceso web, escritorio y móvil

## 📝 Notas Personales (Segundo Cerebro)
- 花了近 100 万美元开发的理财 App，商业化没跑通，现在开源免费用了。

GitHub 上这个项目叫 Sure，目前已有 1.39 万 Stars。

它的前身是 Maybe Finance，原团队停止运营后，由社区接手继续维护。

主要特点：

统一管理个人资产、负债和现金流
查看净资产、收支和财务变化
支持 AI 助手分析个人财务数据
支持 Docker 自托管，数据由自己管理
可通过网页、桌面端和移动端访问
提供 API，支持接入 AI Agent

我比较看重自托管和 AI 接口。个人财务数据比较敏感，能自己控制存储环境，比单纯多几个分析图表更有吸引力。

不过，自托管也意味着备份、更新和安全维护都得自己负责。

你会选择把财务数据交给成熟的云端 App，还是自己部署一套开源理财系统？
