# Rive Web

> Runtime web (JS/WASM) de Rive que conecta animaciones vectoriales interactivas con el estado real de la aplicación mediante state machines.

**👤 Publicado / Recomendado por:** 露西的百宝箱 ([@Lucy_love_AI](https://x.com/Lucy_love_AI))

## 💡 ¿Por qué destaca?
- Reproducción de animaciones vectoriales con runtime WASM y render por GPU

- State machines: la animación reacciona a inputs (booleanos, números, triggers) de la app

- Integración con React, Vue y Web Components

- Assets más ligeros que vídeo y con transiciones fluidas

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para ilustraciones interactivas, onboarding animado o personajes que responden a la lógica de la app, en lugar de vídeos o GIFs pesados.
