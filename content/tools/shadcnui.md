# shadcn/ui

> Colección de componentes UI accesibles y personalizables que se copian al proyecto React/Next.js y quedan bajo tu control.

**👤 Publicado / Recomendado por:** Hasan Toor ([@hasantoxr](https://x.com/hasantoxr))

## 💡 ¿Por qué destaca?
- Componentes basados en Radix UI y Tailwind CSS

- Código copiable en lugar de dependencia de paquete

- Personalización total del diseño y estilos
