# Theatre.js

> Librería JavaScript de animación expresiva con editor visual de timelines para animar DOM, WebGL y objetos 3D en la web.

**👤 Publicado / Recomendado por:** Nero ([@neropursue](https://x.com/neropursue))

## 💡 ¿Por qué destaca?
- Editor visual de secuencias y keyframes integrado con el runtime de la librería

- Animación de propiedades de DOM, objetos Three.js y variables JavaScript

- Estado de animación serializable exportable como JSON y reproducible en producción

- API programática para controlar el playback desde el código de la aplicación

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para animaciones complejas coreografiadas que se salen del alcance de CSS; integra el editor solo en desarrollo y carga el estado exportado en producción para no inflar el bundle.
