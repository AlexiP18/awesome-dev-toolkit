# Annnimate

> Biblioteca de más de 130 animaciones GSAP listas para usar como componentes de React y Vue, ideales para scroll reveals, efectos de texto, sliders y transiciones de página con calidad de estudio.

**👤 Publicado / Recomendado por:** Harshil Tomar ([@Hartdrawss](https://x.com/Hartdrawss))

## 💡 ¿Por qué destaca?
- 130+ animaciones GSAP empaquetadas como componentes React y Vue

- Incluye scroll reveals, efectos tipográficos, sliders y page transitions

- Diseñadas con el estándar de estudios profesionales

## 📝 Notas Personales (Segundo Cerebro)
- Úsala cuando necesites animaciones complejas sin escribir GSAP desde cero, por ejemplo en landings o portfolios con transiciones cuidadas.
