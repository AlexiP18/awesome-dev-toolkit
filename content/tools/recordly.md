# Recordly

> Grabador de pantalla open source para Mac, Windows y Linux que añade zoom automático y cursor suavizado para crear vídeos demo sin editar.

**👤 Publicado / Recomendado por:** KATSU ([@katsudev](https://x.com/katsudev))

## 💡 ¿Por qué destaca?
- Zoom automático y cursor suavizado aplicados durante la grabación

- App de escritorio multiplataforma construida con Electron y TypeScript

- Gratis y open source, sin marcas de agua ni límites de exportación

- Más de 36.000 estrellas en GitHub

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para grabar demos de producto, tutoriales o evidencias visuales de PRs; exporta el vídeo final directamente sin pasar por un editor.
