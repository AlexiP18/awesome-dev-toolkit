# gods-eye-view

> Simulador de satélite espía que corre en el navegador y superpone datos reales de vuelos, barcos y cámaras sobre un globo terráqueo 3D fotorrealista construido con Cesium y WebGL.

**👤 Publicado / Recomendado por:** niko. ([@nikosolenne](https://x.com/nikosolenne))

## 💡 ¿Por qué destaca?
- Visualización geoespacial en tiempo real sobre un globo 3D fotorrealista con Cesium y WebGL

- Capas de seguimiento de vuelos, tráfico marítimo y cámaras públicas con datos abiertos

- Enfoque OSINT que convierte fuentes abiertas en inteligencia espacial consultable

- Aplicación puramente JavaScript que se ejecuta en el navegador sin backend propio

## 📝 Notas Personales (Segundo Cerebro)
- Perfecto para aprender a integrar Cesium con fuentes de datos abiertas o para demos de visualización geoespacial; verifica los términos de uso de cada API de tracking antes de llevarlo a un producto.
