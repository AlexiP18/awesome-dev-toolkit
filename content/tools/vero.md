# Vero

> Agente de codificación con IA que intenta verificar el código generado usando Lean 4, combinando generación y validación formal.

**👤 Publicado / Recomendado por:** Leonard Rodman ([@RodmanAi](https://x.com/RodmanAi))

## 💡 ¿Por qué destaca?
- Utiliza Lean 4 como sistema de verificación formal para comprobar código generado por IA

- Enfocado en agentes de codificación que necesitan mayor fiabilidad y menos alucinaciones

- Repositorio open source implementado en Lean y aún emergente

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para experimentar con pipelines de generación de código asistida por IA donde la verificación formal sea crítica, como prototipos de software de alta confiabilidad.
