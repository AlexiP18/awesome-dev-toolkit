# Cobalt

> Servicio web minimalista y de código abierto que descarga video y audio de redes sociales pegando únicamente la URL, sin anuncios, rastreo ni muros de pago.

**👤 Publicado / Recomendado por:** Precis0x ([@precisox](https://x.com/precisox))

## 💡 ¿Por qué destaca?
- Soporta YouTube, Instagram, TikTok, Twitter/X, Reddit, SoundCloud y más de una decena de plataformas

- Permite elegir formato de salida (mp4, mp3, webm) y calidad de resolución

- Interfaz sin anuncios ni tracking y API pública para integraciones automatizadas

- Diseño ligero que funciona en el navegador sin instalar extensiones

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para descargar videos de referencia, tutoriales o assets de investigación cuando necesitas el archivo local para edición o análisis offline.
