# Awesome LLM Apps

> Repositorio open source en Python con más de 100 aplicaciones de ejemplo listas para ejecutar construidas sobre LLMs, incluyendo agentes avanzados, agentes de voz, equipos multi-agente y pipelines RAG.

**👤 Publicado / Recomendado por:** Erick ([@ErickSky](https://x.com/ErickSky))

## 💡 ¿Por qué destaca?
- Más de 100 apps funcionales organizadas por tipo: Advanced Agents, Voice Agents, Multi-agent Teams, RAG y Agent Skills

- Implementaciones en Python con integración de proveedores de LLM y frameworks de agentes, listas para clonar y ejecutar

- Código abierto y gratuito con ejemplos de extremo a extremo que sirven como plantilla para proyectos reales

- Comunidad muy activa con más de 144k estrellas en GitHub y tópicos de agents, llms y rag

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo como catálogo de referencia y punto de partida para prototipar agentes o sistemas RAG: clona el repo, elige la app más cercana a tu caso de uso y adáptala en lugar de construir la arquitectura desde cero, ahorrando semanas de trabajo inicial.
