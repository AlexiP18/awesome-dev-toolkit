# Thinking Orbs

> Biblioteca de componentes animados con seis tipos de orbes pensados para interfaces, optimizada para tamaños grandes y pequeños y modos claro/oscuro.

**👤 Publicado / Recomendado por:** Jakub Antalik ([@Jakubantalik](https://x.com/Jakubantalik))

## 💡 ¿Por qué destaca?
- Incluye 6 tipos de animaciones de orbes listas para usar en interfaces web.

- Optimizada para renderizar correctamente tanto en tamaños grandes como pequeños.

- Soporta modo claro y oscuro, con playground para probar configuraciones.

- Cero dependencias y distribución vía npm con 'npm install thinking-orbs'.

## 📝 Notas Personales (Segundo Cerebro)
- Úsala cuando necesites indicadores visuales animados ligeros, como estados de carga o elementos decorativos en dashboards y apps React/frontend, evitando añadir dependencias pesadas.
