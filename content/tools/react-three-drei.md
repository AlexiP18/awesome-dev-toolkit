# React Three Drei

> Colección de helpers y utilidades listas para usar que complementan React Three Fiber, facilitando la adición de controles y funciones comunes a escenas 3D en React.

**👤 Publicado / Recomendado por:** Marlen ([@Marlenuii](https://x.com/Marlenuii))

## 💡 ¿Por qué destaca?
- Extiende la funcionalidad de React Three Fiber con componentes 3D preconstruidos.

- Ofrece controles de cámara, efectos, luces y utilidades de renderizado.

- Simplifica la creación de experiencias 3D complejas y personalizadas en React.

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para acelerar el desarrollo de escenas 3D en React, añadiendo funcionalidades avanzadas sin tener que implementarlas desde cero.
