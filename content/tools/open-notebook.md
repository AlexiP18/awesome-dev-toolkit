# Open Notebook

> Implementación open-source de NotebookLM autoalojada en la que puedes cargar PDFs, URLs y vídeos de YouTube para chatear con ellos, resumirlos y generar podcasts usando 18+ proveedores de IA.

**👤 Publicado / Recomendado por:** divyansh tiwari ([@DivyanshT91162](https://x.com/DivyanshT91162))

## 💡 ¿Por qué destaca?
- Ingesta de PDFs, enlaces web y transcripciones de YouTube como fuentes

- Chat contextual, resúmenes automáticos y generación de podcasts

- Soporte para más de 18 proveedores de modelos (locales y en la nube)

## 📝 Notas Personales (Segundo Cerebro)
- Móntalo con Docker si necesitas un asistente de investigación privado para documentación técnica interna sin enviar datos a servicios de terceros.
