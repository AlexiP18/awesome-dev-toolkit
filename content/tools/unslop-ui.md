# unslop-ui

> Herramienta que detecta rasgos de UI genérica generada por IA y ahora aprende tu gusto desde un archivo .unslop-ui/taste.md.

**👤 Publicado / Recomendado por:** fil ([@fildotai](https://x.com/fildotai))

## 💡 ¿Por qué destaca?
- Lista de bans que se vuelven señales extra a buscar en cada ejecución

- Lista de keeps que nunca se recortan y el reporte los marca como intencionales

- Falsos positivos corregidos se guardan como tests reproducibles sin agente ni tokens

## 📝 Notas Personales (Segundo Cerebro)
- unslop-ui now learns your taste.

drop a .unslop-ui/taste.md in your project with two lists.

> bans become extra tells it hunts on every run, like exclamation marks, all caps, or anything else you can't stand.

> keeps never get cut, and the report lists them as kept on purpose.

it also used to flag things that weren't slop, a "New" button read as a badge, a timestamp like "Jan 3 · 14:02" read as a status pill, and != in code counted as an exclamation mark. 

each of those fixes is now saved as a test that replays the case with no agent and no tokens, so the same mistake can't sneak back in
