# React Three Rapier

> Integración del motor de físicas Rapier (Rust/WASM) con React Three Fiber para añadir colisiones, cuerpos rígidos y joints a escenas 3D declarativas.

**👤 Publicado / Recomendado por:** 露西的百宝箱 ([@Lucy_love_AI](https://x.com/Lucy_love_AI))

## 💡 ¿Por qué destaca?
- Componentes declarativos `RigidBody`, `Collider` y joints dentro del árbol R3F

- Motor Rapier compilado a WASM con alto rendimiento y determinismo

- Soporte de sensores, eventos de colisión y fuerzas/impulsos

- API de hooks para consultas y control de la simulación

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para juegos web, configuradores con caída de piezas o demos interactivas donde la física debe sentirse creíble sin salir de React.
