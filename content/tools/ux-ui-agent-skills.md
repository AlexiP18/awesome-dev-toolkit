# ux-ui-agent-skills

> Conjunto de skills que transforma Claude (y Claude Code) en un arquitecto de diseño senior capaz de generar componentes de UI listos para producción y design tokens accesibles bajo el estándar DTCG, con validación automática de calidad.

**👤 Publicado / Recomendado por:** Tom Dörr ([@tom_doerr](https://x.com/tom_doerr))

## 💡 ¿Por qué destaca?
- Genera design tokens en formato DTCG (Design Tokens Community Group) listos para integrarse en pipelines de diseño a código

- Catálogo de 52 componentes reutilizables y compatibilidad con 138 design systems distintos, con salida de código agnóstica al framework (React, Tailwind, etc.)

- Cumplimiento WCAG 2.2 en niveles AA-AAA con verificación de contraste, semántica y accesibilidad de teclado

- 50 gates objetivos de calidad que hacen fallar la build en lugar de simular éxito, evitando componentes incompletos o con deuda de accesibilidad

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo cuando necesites que un agente de IA genere sistemas de diseño o componentes UI consistentes y accesibles desde Figma o una especificación; revisa los gates de validación en CI para asegurar que ningún componente con fallos de contraste o semántica llegue a producción.
