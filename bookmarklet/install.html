Bookmarklet: guardar en el toolkit con un clic

Guarda un tweet de X mientras navegas. El marcador abre /quick-save y no choca con la política de seguridad de X.

  1. Muestra la barra de marcadores (Ctrl + Shift + B o Cmd + Shift + B).
  2. Si ya tenías una versión anterior del marcador, bórrala primero.
  3. Arrastra el botón hacia la barra de marcadores. En el móvil, mantén pulsado el botón y elige copiar o compartir el enlace.

Hilos. Si el tweet forma parte de un hilo del mismo autor, el bookmarklet recoge los tweets visibles, expande el texto cortado y los manda juntos como un solo recurso.
