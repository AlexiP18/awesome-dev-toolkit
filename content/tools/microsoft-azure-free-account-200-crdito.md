# Microsoft Azure Free Account ($200 crédito)

> Cuenta gratuita de Azure con $200 de crédito válido 30 días para cualquier servicio, siendo la vía directa y oficial para consumir modelos GPT mediante Azure OpenAI sin pagar tokens. Incluye además más de 20 servicios gratis 12 meses y 65+ siempre gratuitos.

## 💡 ¿Por qué destaca?
- $200 de crédito gastable en cualquier servicio de Azure durante 30 días

- Acceso a Azure OpenAI para usar modelos GPT con la API oficial de Microsoft

- 20+ servicios gratuitos durante 12 meses y 65+ servicios always free

- Ventana de 30 días sin extensión ni reemisión del crédito no utilizado
