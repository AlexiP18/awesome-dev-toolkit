# TinEye

> Motor de búsqueda inversa de imágenes que localiza dónde se ha publicado una imagen y sus versiones modificadas.

**👤 Publicado / Recomendado por:** Alejo ([@ecommartinez](https://x.com/ecommartinez))

## 💡 ¿Por qué destaca?
- Indexación de miles de millones de imágenes

- Ordenación por fecha de aparición y tamaño

- API para integraciones automatizadas

## 📝 Notas Personales (Segundo Cerebro)
- Empléalo para verificar la procedencia de una imagen o comprobar si un asset de diseño ya existe en la web.
