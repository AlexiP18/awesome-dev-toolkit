# BatteryHub

> App de ~350 KB para Windows que muestra en la barra de tareas la batería del ratón, teclado y cascos sin el software de cada marca.

**👤 Publicado / Recomendado por:** PA13L0 ([@Fluyeporlaweb](https://x.com/Fluyeporlaweb))

## 💡 ¿Por qué destaca?
- Windows 10 y 11, unos 2 MB de RAM, licencia GPL-3.0

- Soporta Logitech, Razer, SteelSeries, Corsair, HyperX y mandos PlayStation/Xbox

- Historial local sin cuenta ni nube; no está firmada

- El tuit no trae el enlace al repo (está en el primer comentario): revisar URL

## 📝 Notas Personales (Segundo Cerebro)
- SI USAS WINDOWS ESTO TE INTERESA

Alguien subió a GitHub una app de 350 KB que te pone la batería del ratón, el teclado y los cascos en la barra de tareas, sin el software de cada marca.

Se llama BatteryHub.

4.8K estrellas desde el 16 de noviembre.
Licencia GPL-3.0.

✅ Windows 10 y 11
✅ Ocupa unos 2 MB de RAM
✅ Logitech, Razer, SteelSeries, Corsair, HyperX, mandos de PlayStation y Xbox, y lo que Windows ya sepa por Bluetooth
✅ El historial de batería se queda en tu ordenador, sin cuenta ni nube

Ojo: Windows puede avisar al abrirla porque no está firmada.
El README lo explica.

Y si solo lo usas para el ratón, ya te quitas de instalar el programa de la marca.
