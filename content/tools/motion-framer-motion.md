# Motion (Framer Motion)

> Librería de animación para React y JavaScript que anima layouts, gestos, scroll y transiciones de estado con una API declarativa y un motor de físicas optimizado.

**👤 Publicado / Recomendado por:** 露西的百宝箱 ([@Lucy_love_AI](https://x.com/Lucy_love_AI))

## 💡 ¿Por qué destaca?
- Animaciones de layout automáticas con `layout` y `AnimatePresence` para montaje/desmontaje

- Gestos integrados: drag, hover, tap y seguimiento del puntero

- Soporte de valores animados, springs y `MotionValue` para animaciones performantes

- Compatible con React, Vue y Vanilla JS

## 📝 Notas Personales (Segundo Cerebro)
- Úsala para microinteracciones, transiciones de página y listas animadas en apps React, aprovechando `layout` para evitar cálculos manuales de posiciones.
