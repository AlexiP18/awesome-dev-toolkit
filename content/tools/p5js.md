# p5.js

> Una plataforma de JavaScript del lado del cliente diseñada para el código creativo, permitiendo a artistas, diseñadores y estudiantes crear gráficos, animaciones y experiencias interactivas en la web de manera accesible.

**👤 Publicado / Recomendado por:** eigen ([@e1genqq](https://x.com/e1genqq))

## 💡 ¿Por qué destaca?
- Diseñado para codificación creativa y arte generativo visual

- Simplifica la creación de gráficos y animaciones interactivas web

- Basado en los principios de Processing, facilitando el aprendizaje

- Amplia comunidad activa y abundantes recursos educativos

## 📝 Notas Personales (Segundo Cerebro)
- Útil para experimentar con visualizaciones interactivas, arte digital generativo y prototipos creativos con un enfoque educativo y exploratorio.
