# OpenDesign

> Un espacio de trabajo de diseño de código abierto impulsado por IA, alternativa a Claude Design, para construir prototipos, landing pages y dashboards con tu propio agente de codificación.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Generación de prototipos, landing pages, dashboards, slides y video HTML

- Funciona con agentes de codificación personalizados

- Alternativa de código abierto a Claude Design

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para desarrolladores que buscan automatizar el diseño de interfaces web utilizando inteligencia artificial.
