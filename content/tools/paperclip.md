# paperclip

> Aplicación open source en TypeScript para orquestar un equipo de agentes autónomos de IA, asignarles tareas y supervisarlos como si fueran empleados de tu propia empresa.

**👤 Publicado / Recomendado por:** niko. ([@nikosolenne](https://x.com/nikosolenne))

## 💡 ¿Por qué destaca?
- Orquestación multi-agente con roles, tareas y seguimiento de estado

- Integración con Claude Code, Codex y skills de agente a través de MCP

- Automatización de flujos de trabajo y gobernanza de agentes (ai-governance)

- App web en TypeScript pensada para gestionar agentes en el día a día laboral

## 📝 Notas Personales (Segundo Cerebro)
- Adóptalo cuando tengas varios agentes sueltos y necesites centralizar su gestión; define permisos y límites de coste antes de dejarlos operar de forma autónoma.
