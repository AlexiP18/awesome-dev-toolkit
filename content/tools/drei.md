# Drei

> Colección de helpers y abstracciones reutilizables para React Three Fiber: cámaras con controles, texto 3D, entornos, sombras de contacto y carga de modelos.

**👤 Publicado / Recomendado por:** 露西的百宝箱 ([@Lucy_love_AI](https://x.com/Lucy_love_AI))

## 💡 ¿Por qué destaca?
- `OrbitControls`, `PointerLockControls` y `PresentationControls` listos para usar

- Componentes de texto, HTML sobre 3D, `Environment` y `ContactShadows`

- Cargadores (`useGLTF`, `useTexture`) con caché y precarga

- Utilidades de rendimiento como `AdaptiveDpr` y `Instances`

## 📝 Notas Personales (Segundo Cerebro)
- Añade drei a cualquier proyecto R3F para evitar reescribir controles, textos y luces de entorno; ahorra cientos de líneas de setup.
