# JCodesMore AI Website Cloner Template

> Plantilla open source que clona cualquier sitio web a partir de su URL usando más de 10 agentes de IA en paralelo, entregando un proyecto Next.js + Tailwind limpio y listo para desarrollar y publicar.

**👤 Publicado / Recomendado por:** Sweex ([@sweexx9](https://x.com/sweexx9))

## 💡 ¿Por qué destaca?
- Analiza colores, tipografías y espaciados del sitio original al milímetro para replicar el design system

- Captura y desmenuza cada sección de la página antes de generar código, evitando maquetación a ciegas

- Distribuye el trabajo entre +10 agentes de IA en paralelo y es compatible con más de 10 agentes de programación, incluyendo Claude Code

- Devuelve un codebase completo en Next.js + Tailwind estructurado, ordenado y listo para completar y desplegar

- Proyecto con más de 31.200 estrellas en GitHub, lo que garantiza comunidad activa y ejemplos de uso

## 📝 Notas Personales (Segundo Cerebro)
- Úsala para levantar rápidamente un prototipo o clon de referencia de una landing existente y luego refactorizar el código generado: revisa licencias y derechos del sitio original antes de publicar, y ajusta manualmente los componentes generados para adaptarlos a tu propio branding y contenido.
