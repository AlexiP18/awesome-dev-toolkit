# claude-mem

> Sistema de memoria para agentes que registra lo que ha hecho cada sesión, lo resume y lo inyecta en la siguiente para que el agente no arranque desde cero.

**👤 Publicado / Recomendado por:** niko. ([@nikosolenne](https://x.com/nikosolenne))

## 💡 ¿Por qué destaca?
- Persistencia y resumen automático del historial de acciones del agente

- Inyección de contexto en la siguiente sesión para mantener la continuidad del trabajo

- Compatible con Claude Code y flujos de agentes basados en CLI

- Reduce la repetición de contexto y el consumo innecesario de tokens

## 📝 Notas Personales (Segundo Cerebro)
- Muy útil en proyectos largos donde el agente pierde el hilo; conviene revisar periódicamente la memoria resumida para no arrastrar contexto obsoleto o incorrecto entre sesiones.
