# uisfx

> Librería open source de sonidos de interfaz para productos web: 936 efectos listos para usar, instalable vía npm y reproducible con una sola línea de código para dar feedback sonoro a botones, modales y notificaciones.

**👤 Publicado / Recomendado por:** Manish Kumar ([@Manixh02](https://x.com/Manixh02))

## 💡 ¿Por qué destaca?
- Catálogo de 936 sonidos de interfaz listos para producción, organizados por familias de estilo

- 12 'feels' o estilos sonoros distintos: minimal, glass, arcade y zen, entre otros

- Instalación con npm install uisfx y reproducción de cues en una única línea de JavaScript

- Audio bajo licencia CC0 y código fuente bajo licencia MIT, apto para uso comercial sin atribución

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para añadir micro-feedback sonoro accesible y no intrusivo en SPAs o apps React/Vue: importa el paquete, elige un 'feel' coherente con la identidad de marca y dispara los cues en eventos de click, éxito o error; al ser CC0 puedes distribuir los audios sin preocupaciones legales.
