# MNMM

> Directorio de sitios web minimalistas que recopila interfaces limpias y de bajo ruido visual para inspirar diseños enfocados en contenido.

**👤 Publicado / Recomendado por:** Tran Mau Tri Tam ✪ ([@tranmautritam](https://x.com/tranmautritam))

## 💡 ¿Por qué destaca?
- Curaduría centrada en minimalismo y simplicidad extrema

- Referencias de layouts con amplio espacio en blanco y tipografía contenida

- Útil para portfolios, documentación y landings de producto

- Consúltalo cuando busques reducir la carga visual de una interfaz o definir un sistema de espaciado y tipografía sobrio.
