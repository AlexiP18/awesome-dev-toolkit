# Ollama

> Runtime para ejecutar modelos de lenguaje de código abierto localmente con un comando, útil por privacidad y coste.

**👤 Publicado / Recomendado por:** Matt Dancho (Business Science) ([@mdancho84](https://x.com/mdancho84))

## 💡 ¿Por qué destaca?
- Ejecuta LLMs open-source en local con comandos simples.

- Facilita pruebas y desarrollo sin depender de APIs externas.

- Soporta modelos populares y despliegue en máquinas propias.

## 📝 Notas Personales (Segundo Cerebro)
- Empléalo para prototipos offline, pruebas de privacidad o reducir costes de inferencia; verifica los requisitos de hardware.
