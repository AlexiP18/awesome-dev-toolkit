# animos

> Editor de plantillas de motion prediseñadas para presentar diseños: arrastras imágenes o vídeos, ajustas parámetros y exportas MP4 o WebM directamente desde el navegador.

**👤 Publicado / Recomendado por:** Harshil Tomar ([@Hartdrawss](https://x.com/Hartdrawss))

## 💡 ¿Por qué destaca?
- Plantillas de animación listas para escaparates o showcases de producto

- Entrada de assets propios (imágenes y vídeo) con ajuste de parámetros en el editor

- Exportación de vídeo MP4 y WebM procesada en el cliente, sin instalar software

## 📝 Notas Personales (Segundo Cerebro)
- Perfecto para crear clips de presentación de mockups, case studies de portfolio o vídeos para redes de un proyecto web sin abrir After Effects.
