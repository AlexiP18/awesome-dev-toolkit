# OriginKit

> Biblioteca gratuita de componentes UI animados y listos para integrar en proyectos web modernos, ideal para acelerar la construcción de interfaces con movimiento sin escribir animaciones desde cero.

**👤 Publicado / Recomendado por:** Tran Mau Tri Tam ✪ ([@tranmautritam](https://x.com/tranmautritam))

## 💡 ¿Por qué destaca?
- Componentes animados reutilizables de uso libre y gratuito

- Enfoque en microinteracciones y transiciones de interfaz

- Pensada para integrarse en stacks frontend modernos basados en componentes

## 📝 Notas Personales (Segundo Cerebro)
- Perfecta para prototipos y MVPs donde necesitas movimiento pulido rápido; revisa las props antes de integrarla para mantener consistencia con tu design system.
