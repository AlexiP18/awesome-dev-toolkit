# Lottie Web

> Librería JavaScript para renderizar animaciones de After Effects exportadas como JSON (formato Lottie) en la web, permitiendo reproducir animaciones vectoriales ligeras en escenas basadas en la web.

**👤 Publicado / Recomendado por:** Marlen ([@Marlenuii](https://x.com/Marlenuii))

## 💡 ¿Por qué destaca?
- Reproduce animaciones vectoriales de forma eficiente en entornos web.

- Utiliza archivos JSON ligeros, optimizados para el rendimiento.

- Permite una integración sencilla con After Effects y exportación de animaciones.

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para añadir animaciones complejas y de alta calidad a interfaces web sin comprometer el rendimiento, como iconos animados o ilustraciones dinámicas en videos.
