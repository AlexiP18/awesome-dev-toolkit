# ArchiveBox

> Archivador web self-hosted en Python que guarda una copia permanente de cualquier enlace: HTML, PDF, captura de pantalla y vídeo, todo en tu propio disco.

**👤 Publicado / Recomendado por:** Sentient ([@sentient_agency](https://x.com/sentient_agency))

## 💡 ¿Por qué destaca?
- Captura en múltiples formatos: HTML, PDF, WARC, screenshot y media

- Interfaz web y CLI para consultar y buscar el archivo histórico

- Indexación full-text del contenido archivado

- Ejecución programada de snapshots sobre listas de URLs

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo como Wayback Machine personal para preservar documentación, artículos o referencias que pueden editarse o desaparecer con el tiempo.
