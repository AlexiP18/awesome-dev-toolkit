# OpenBot

> Compañeros de trabajo con IA open source de CopilotKit que disponen de su propio navegador, archivos y herramientas para ejecutar tareas de forma gobernada.

**👤 Publicado / Recomendado por:** brenz. ([@brenzhills](https://x.com/brenzhills))

## 💡 ¿Por qué destaca?
- Cada agente opera con un ordenador propio: navegador, ficheros y tools

- Registra y decide acciones antes/después para gobernanza y auditoría

- Compatible con agentes AG-UI y automatización de navegador

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para desplegar agentes que necesitan navegar y manipular archivos con trazabilidad; revisa permisos y sandboxing.
