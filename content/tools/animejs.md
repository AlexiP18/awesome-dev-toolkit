# Anime.js

> Librería de animación ligera en JavaScript para animar rutas SVG, texto, propiedades CSS y objetos JS con una API sencilla de keyframes y stagger.

**👤 Publicado / Recomendado por:** 露西的百宝箱 ([@Lucy_love_AI](https://x.com/Lucy_love_AI))

## 💡 ¿Por qué destaca?
- Animación de trazos SVG y morphing de paths con `anime.path`

- Timeline y stagger para animaciones en cascada de listas y elementos

- Soporte de keyframes, easings personalizados y animación de atributos DOM

- Tamaño reducido y sin dependencias

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para landings y prototipos donde quieres efectos vistosos (trazos, staggered text) sin el peso ni la complejidad de GSAP.
