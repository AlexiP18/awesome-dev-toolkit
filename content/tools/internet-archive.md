# Internet Archive

> Biblioteca digital sin ánimo de lucro que conserva versiones históricas de páginas web mediante Wayback Machine además de textos y multimedia.

**👤 Publicado / Recomendado por:** Alejo ([@ecommartinez](https://x.com/ecommartinez))

## 💡 ¿Por qué destaca?
- Wayback Machine con snapshots fechados de millones de sitios

- API de disponibilidad para consultar versiones archivadas

- Colecciones de libros, software antiguo y audio descargables

## 📝 Notas Personales (Segundo Cerebro)
- Útil para recuperar documentación eliminada de una librería o comprobar cómo era una API antes de un cambio de versión.
