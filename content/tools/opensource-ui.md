# Opensource UI

> Librería gratuita de UI para React y Next.js que ofrece más de 200 componentes listos para copiar y personalizar, con licencia MIT y soporte para Tailwind CSS y TypeScript.

**👤 Publicado / Recomendado por:** Houdayfa ([@HoudayfaDesign](https://x.com/HoudayfaDesign))

## 💡 ¿Por qué destaca?
- Componentes React y Next.js gratuitos

- Listos para copiar y personalizar (copy-paste)

- Licencia MIT

- Más de 200 componentes, bloques Tailwind CSS y mockups

## 📝 Notas Personales (Segundo Cerebro)
- Excelente recurso para desarrolladores que necesitan una amplia gama de componentes UI de código abierto para sus proyectos React y Next.js sin coste alguno.
