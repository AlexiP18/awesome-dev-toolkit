# BrowserSkill

> Herramienta open-source de Tencent que permite a agentes de IA controlar tu navegador real con sesiones ya autenticadas, sin interrumpir tu trabajo, mediante CLI y extensión.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Automatización de navegador usando el perfil real y logueado del usuario

- Compatible con cualquier agente de IA capaz de ejecutar shell

- Distribución dual: CLI más extensión de navegador

- Implementado en TypeScript y publicado bajo tópicos de agent y browser-use

## 📝 Notas Personales (Segundo Cerebro)
- Ideal para tareas de scraping autenticado, relleno de formularios internos o flujos web con login donde un navegador headless fallaría por falta de sesión.
