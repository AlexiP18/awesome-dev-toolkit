# Stream Tube Desktop

> Cliente nativo de YouTube para escritorio escrito en Rust, para Windows y Linux.

**👤 Publicado / Recomendado por:** Ram Maheshwari ([@rammcodes](https://x.com/rammcodes))

## 💡 ¿Por qué destaca?
- Integra SponsorBlock, DeArrow y Return YouTube Dislike

- Reproducción con MPV y decodificación por hardware

- Descargas con yt-dlp y suscripciones locales sin iniciar sesión

- Importa suscripciones de NewPipe, FreeTube y Google Takeout; el tuit no trae enlace al repo

## 📝 Notas Personales (Segundo Cerebro)
- Ain't no freakin wayyy... we really got a Rust-based YouTube client before Read Dead Redemption 3 🥵🔥

Someone cooked a native YouTube desktop app called Stream Tube Desktop.

It comes with...

~ SponsorBlock to skip sponsor segments.
~ DeArrow for better titles and thumbnails.
~ Return YouTube Dislike.
~ MPV video playback with hardware decoding.
~ Picture-in-picture and background playback.
~ Video downloads using yt-dlp.
~ Local subscriptions without signing in.
~ Import subscriptions from NewPipe, FreeTube and Google Takeout.

Available for Windows and Linux :)
