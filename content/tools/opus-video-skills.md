# opus-video-skills

> Una colección de habilidades de Claude Code para Claude Opus 5.5, que permite la creación de videos con diferentes estilos como animación pintada a mano y tipografía cinética, donde cada elemento se genera en código.

**👤 Publicado / Recomendado por:** Leonard Rodman ([@RodmanAi](https://x.com/RodmanAi))

## 💡 ¿Por qué destaca?
- Ofrece habilidades específicas de Claude Code para distintos estilos de creación de video.

- Permite la generación programática de cada fotograma y nota musical en el video.

- Incluye estilos como animación pintada a mano, tipografía cinética y videos de letras de canciones.

## 📝 Notas Personales (Segundo Cerebro)
- Muy útil para desarrolladores y creativos que desean experimentar con la generación de video estilizado y altamente personalizable a través de código y asistencia de IA.
