# Spline

> Herramienta de diseño 3D en el navegador con colaboración en tiempo real para modelar, animar y publicar escenas interactivas dentro de webs.

**👤 Publicado / Recomendado por:** Nero ([@neropursue](https://x.com/neropursue))

## 💡 ¿Por qué destaca?
- Editor 3D 100% en navegador con colaboración multiusuario en tiempo real

- Exportación e incrustación de escenas interactivas directamente en sitios web

- Animación, materiales y eventos para construir experiencias 3D ligeras

- Versión gratuita disponible para equipos y agentes de diseño

## 📝 Notas Personales (Segundo Cerebro)
- Perfecta para heroes o secciones inmersivas de una landing; cuida el peso del bundle y usa carga diferida del canvas para no penalizar el rendimiento móvil.
