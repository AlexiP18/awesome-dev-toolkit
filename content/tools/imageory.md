# Imageory

> Imageory es una galería personal de imágenes generadas por IA que recopila prompts listos para usar, permitiendo a los desarrolladores y creadores inspirarse y reutilizar instrucciones para generar visuales de alta calidad.

**👤 Publicado / Recomendado por:** Houdayfa ([@HoudayfaDesign](https://x.com/HoudayfaDesign))

## 💡 ¿Por qué destaca?
- Colección de prompts de IA orientados a la creación de imágenes visuales impactantes

- Galería personal de imágenes con acceso directo a los prompts asociados

- Acceso con un clic para guardar y reutilizar prompts en generadores de imágenes

- Recurso gratuito para inspirarse y acelerar la creación de contenido visual

## 📝 Notas Personales (Segundo Cerebro)
- Úsala cuando necesites prompts probados para generar imágenes con herramientas como Midjourney, DALL-E o Stable Diffusion, o como fuente de inspiración para diseñar tus propios prompts visuales.
