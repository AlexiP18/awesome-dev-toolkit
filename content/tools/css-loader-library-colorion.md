# CSS Loader Library (Colorion)

> Biblioteca de 99 spinners de carga en CSS puro, con licencia MIT, que permite copiar el código de cada loader con un clic y prompts de IA listos para usar.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- 99 loaders construidos con CSS puro, sin JavaScript ni dependencias

- Copiar el CSS de cualquier spinner con un solo clic

- Prompts de IA incluidos para regenerar o adaptar cada animación

- Licencia MIT para uso libre en proyectos comerciales

## 📝 Notas Personales (Segundo Cerebro)
- Perfecta para añadir estados de carga ligeros y sin dependencias en cualquier interfaz web; copia el CSS directamente y ajústalo a tu paleta con variables CSS.
