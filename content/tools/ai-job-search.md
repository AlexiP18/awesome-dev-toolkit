# ai-job-search

> Agente construido sobre Claude Code que automatiza la búsqueda de empleo: evalúa la oferta, adapta tu CV, redacta la carta de presentación y prepara la entrevista.

**👤 Publicado / Recomendado por:** PA13L0 ([@Fluyeporlaweb](https://x.com/Fluyeporlaweb))

## 💡 ¿Por qué destaca?
- Evalúa y puntúa ofertas de trabajo automáticamente

- Adapta el CV y redacta cover letters personalizadas

- Prepara al usuario para la entrevista

- Construido como framework sobre Claude Code, basado en Python
