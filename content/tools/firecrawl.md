# Firecrawl

> API y librería de crawling que convierte cualquier web en texto limpio en markdown listo para alimentar a tus agentes de IA y pipelines RAG.

**👤 Publicado / Recomendado por:** KATSU ([@katsudev](https://x.com/katsudev))

## 💡 ¿Por qué destaca?
- Convierte HTML a markdown optimizado para LLMs

- Crawler y scraper con extracción estructurada de datos

- Búsqueda web y endpoints preparados para RAG

- Más de 199.000 estrellas en GitHub, escrito en TypeScript

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo para ingestar documentación o sitios web en tu pipeline RAG; respeta robots.txt y limita el rate para no saturar los sitios de origen.
