# BoxLite

> Plataforma open source (Apache 2.0) que ejecuta agentes de IA en microVMs aisladas, con versión cloud gestionada o self-hosted.

**👤 Publicado / Recomendado por:** CS ([@CallMeCSZ](https://x.com/CallMeCSZ))

## 💡 ¿Por qué destaca?
- Hasta 4 vCPU y 32 GiB de RAM por microVM con disco persistente

- URLs públicas para desplegar y compartir apps

- Sirve para correr Claude Code, intérpretes de código o automatización con Playwright

- 100 USD de créditos gratis para cuentas nuevas según el tuit
