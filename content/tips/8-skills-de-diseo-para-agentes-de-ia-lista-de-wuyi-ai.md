# 💡 8 skills de diseño para agentes de IA (lista de @wuyi_ai)

> Lista de ocho skills de diseño para que los agentes de código generen interfaces con mejor criterio visual; el tuit no trae enlaces, solo nombres y estrellas.

**👤 Publicado / Recomendado por:** 五一同学 ([@wuyi_ai](https://x.com/wuyi_ai))

## 📌 Puntos Clave & Pasos del Consejo
- Las tres recomendadas: ui-ux-pro-max (90.4k★), taste-skill (41.4k★) y huashu-design (24.2k★)

- También: MengTo Skills, scroll-world (landings 3D con scroll), emilkowalski/skills (animación) y awesome-design-skills (índice)

- Frontend Design Skill oficial de Anthropic: fija tipografía, color y layout antes de escribir código

## 📝 Aplicación Práctica & Contexto
- AI做UI丑？ 这8个设计Skill，让它秒变设计总监！

🔖赶紧收藏!  ( 前 3 个必装) 

1. ui-ux-pro-max（90.4k星）🏆
—设计类的绝对一哥，配色、字体、布局、动效、多技术栈规则全在里面，装它等于给AI塞了一本设计学院教材。

2.  taste-skill（41.4k星）🏆
—专治AI味，提升品味判断，让它知道什么该删。

3.  huashu-design（24.2k星）🏆
—设计哲学到高保真到视觉QA一条龙，流程最完整。

4. MengTo Skills（6.1k星）
—设计师出品，重参考、重判断；

5. scroll-world（4.6k星）
—做高端3D滚动Landing Page的神器；

6. emilkowalski/skills（2.6k星）
—动画细节大师，界面手感就靠它。

7. awesome-design-skills（1.3k星）
一份索引全搞定。

8.  Frontend Design Skill
Anthropic官方的, 强制AI先定字体、配色、版式再写代码。
