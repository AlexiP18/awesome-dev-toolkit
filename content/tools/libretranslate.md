# LibreTranslate

> Motor de traducción automática self-hosted basado en modelos Argos Translate que traduce texto y documentos completos de forma offline, sin API key ni coste por carácter.

**👤 Publicado / Recomendado por:** Sentient ([@sentient_agency](https://x.com/sentient_agency))

## 💡 ¿Por qué destaca?
- API REST con endpoint /translate y /detect compatible con clientes habituales

- Modelos de traducción locales descargables para decenas de idiomas

- Traducción de archivos completos (.txt, .docx, .pdf) vía batch

- Despliegue con Docker, pip o desde el código fuente

## 📝 Notas Personales (Segundo Cerebro)
- Perfecto para traducir contenido en lotes o en entornos sin conexión; integra su endpoint en tu backend para eliminar cuotas de APIs comerciales.
