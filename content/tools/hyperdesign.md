# HyperDesign

> Herramienta que analiza visualmente cualquier sitio web a partir de su URL y genera un archivo DESIGN.md con su sistema de diseño completo: colores, tipografía, espaciado y componentes de UI.

**👤 Publicado / Recomendado por:** Abraham John ([@Abmankendrick](https://x.com/Abmankendrick))

## 💡 ¿Por qué destaca?
- Extracción visual del design system completo de un sitio web pegando únicamente la URL

- Genera un archivo DESIGN.md exportable con paleta de colores, escalas tipográficas, tokens de espaciado y componentes UI

- Compatible con asistentes de código como Claude Code, Cursor y otros flujos de 'vibe coding' para dar contexto de diseño al agente

- Implementado sobre Hyperbrowser; los ejemplos funcionales están publicados en TypeScript dentro del repositorio oficial

## 📝 Notas Personales (Segundo Cerebro)
- Úsala al iniciar un proyecto frontend para replicar o inspirarte en un design system existente: genera el DESIGN.md, guárdalo en la raíz del repo y pásalo como contexto a Cursor o Claude Code para que el código generado respete colores, tipografía y espaciados reales.
