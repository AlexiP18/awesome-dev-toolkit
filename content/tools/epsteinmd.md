# epstein.md

> Archivo Markdown de más de 927.400 caracteres que actúa como guía de estilo y reglas de diseño para asistentes de código con IA, impidiendo que generen interfaces genéricas propias del 'AI slop' y forzando decisiones visuales sobrias y profesionales. Está integrado en el vibe coder de Shipper.now.

**👤 Publicado / Recomendado por:** Shipper ([@shipper_now](https://x.com/shipper_now))

## 💡 ¿Por qué destaca?
- Prohíbe patrones visuales típicos de UI generada por IA: box shadows, emojis decorativos, badges tipo '🟢 LIVE' y degradados azul/púrpura

- Ignora de forma explícita las 350 palabras y muletillas más comunes en textos generados por IA (delve, vibe, seamless, etc.)

- Se inyecta como contexto/reglas en el pipeline del vibe coder de Shipper.now para que el código de UI generado respete esas restricciones

- Creado a partir de 11 meses de curaduría manual sobre principios de diseño y anti-patrones de interfaces generadas automáticamente

## 📝 Notas Personales (Segundo Cerebro)
- Útil para equipos que generan frontend con agentes de IA y quieren evitar resultados visualmente clónicos; conviene revisar y adaptar las reglas a la identidad de marca del proyecto antes de usarlo como system prompt o archivo de contexto.
