# Ship Studio

> Aplicación de escritorio gratuita y open source que integra un agente de IA, repositorios y despliegues en una sola ventana para desarrollar y publicar desde la máquina local.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Se ejecuta localmente y se conecta a suscripciones, cuenta de GitHub y hosting existentes

- Reúne agente, repositorio y despliegues en un único flujo de trabajo

- Enfocada en desarrollo agéntico open source sin salir de la aplicación

## 📝 Notas Personales (Segundo Cerebro)
- Útil para prototipar y desplegar proyectos rápidamente con un agente que opera sobre el repositorio y el hosting ya configurados.
