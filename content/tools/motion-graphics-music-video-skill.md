# motion-graphics-music-video-skill

> Un plugin para Claude Opus 5.5 que transforma una pista de música y un prompt en un video de motion graphics de alta calidad, simplificando la producción audiovisual.

**👤 Publicado / Recomendado por:** Leonard Rodman ([@RodmanAi](https://x.com/RodmanAi))

## 💡 ¿Por qué destaca?
- Genera videos de motion graphics directamente desde un archivo de audio y un prompt de texto.

- Diseñado como un plugin específico para el modelo Claude Opus 5.5.

- Produce resultados visuales de alta calidad adecuados para videos musicales o promocionales.

## 📝 Notas Personales (Segundo Cerebro)
- Perfecto para músicos, creadores de contenido o diseñadores que necesitan videos promocionales o visualizadores de música de forma rápida y eficiente con IA.
