# MotionSites Studio

> Estudio web con IA que parte de plantillas de sitios con motion y 3D ya diseñadas: describes tu negocio, la IA adapta objeto, colores y copy, genera imágenes/video y entrega el código descargable.

**👤 Publicado / Recomendado por:** Viktor Oddy ([@viktoroddy](https://x.com/viktoroddy))

## 💡 ¿Por qué destaca?
- Genera un sitio personalizado a partir de una descripción de negocio sobre diseños MotionSites preexistentes

- Permite editar el objeto 3D, la paleta de colores y el copy de la plantilla antes de exportar

- Crea automáticamente imágenes y vídeos asociados al proyecto

- Descarga del código fuente del sitio resultante para integrarlo o desplegarlo por tu cuenta

- El catálogo de prompts originales está disponible en motionsites.ai para replicar el workflow

## 📝 Notas Personales (Segundo Cerebro)
- Úsalo como punto de partida para landings de producto o portfolios con animaciones 3D: ajusta el prompt de motionsites.ai, sustituye el objeto y la paleta por tu branding y revisa el código exportado antes de pasarlo a producción (peso de assets 3D y rendimiento móvil).
