# Storyset

> Editor online de ilustraciones personalizables de Freepik que permite recolorear escenas, ocultar elementos y animarlas para exportarlas como SVG o PNG.

**👤 Publicado / Recomendado por:** 𝐍𝐨𝐚𝐡 ([@noahelhadedy](https://x.com/noahelhadedy))

## 💡 ¿Por qué destaca?
- Editor web con control de colores, fondo y elementos individuales

- Estilos múltiples: Bro, Rafiki, Amico, Pana, Cuate y más

- Animaciones listas para exportar y usar en web o apps

- Descarga en SVG y PNG con licencia gratuita atribuyendo la fuente

## 📝 Notas Personales (Segundo Cerebro)
- Úsala cuando necesites escenas coherentes y animadas para secciones hero o tutoriales dentro de una interfaz web o móvil.
