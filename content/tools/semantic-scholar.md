# Semantic Scholar

> Buscador académico gratuito con IA que indexa millones de papers y extrae citas, resúmenes y relaciones entre artículos.

**👤 Publicado / Recomendado por:** Alejo ([@ecommartinez](https://x.com/ecommartinez))

## 💡 ¿Por qué destaca?
- API abierta (S2 API) para consultas programáticas

- Resúmenes generados por IA (TLDR) por paper

- Grafo de citas y referencias navegable

## 📝 Notas Personales (Segundo Cerebro)
- Perfecto para fundamentar decisiones de arquitectura o algoritmos con literatura revisada y para construir datasets de investigación.
