# Iconaut

> Un set de iconos de código abierto que ofrece más de 1,230 iconos de interfaz gratuitos en estilos de línea, sólido y duotono, optimizados para React, Figma y SVG, facilitando la integración en cualquier proyecto de diseño y desarrollo web.

**👤 Publicado / Recomendado por:** Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi))

## 💡 ¿Por qué destaca?
- Cuenta con más de 1,230 iconos de interfaz totalmente gratuitos.

- Disponibles en tres estilos: línea, sólido y duotono.

- Diseñados meticulosamente en una cuadrícula de 24px para una consistencia visual.

- Se pueden instalar a través de npm, copiar el SVG directamente o clonar el repositorio.

- Ideal para proyectos en React y diseños en Figma.

## 📝 Notas Personales (Segundo Cerebro)
- Perfecto para diseñadores y desarrolladores que necesitan iconos consistentes, de alta calidad y listos para usar en sus aplicaciones web o prototipos de Figma, sin coste alguno.
